## 16. Altera Agilex 7 — detailed family plan (device overview 683458, rev 2025.12.08)

- F-Series FPGAs span **392,000 to 2,692,760 logic elements** (AGF 006 through AGF 027) `[official]` — source: https://www.mouser.com/catalog/specsheets/Intel Corporation_04-17-2026_ag-overview-683458-666707.pdf `[official]`
- F-Series memory: M20K blocks **1,900–13,272** (up to 259 Mbit), MLAB **6,644–45,640** (up to 29.2 Mbit); DSP delivers **1.7–11.8 TFLOPS** single precision `[official]`
- F-Series transceivers: up to **58 Gbps** (FGT/FGTA); F-Tile and P-Tile PCIe hard IP (Gen4 x16, bifurcatable); 2–4× F-Tile 10/25/50/100/200/400G Ethernet MAC + FEC hard IP `[official]`
- F-Series SoC variants add quad-core **Arm Cortex-A53 up to 1.5 GHz** (32 KB I/D, NEON, 1 MB L2, DMA, SMMU, cache coherency), DDR4/QDR IV/RLDRAM 3 support `[official]` — source: https://www.cnx-software.com/2019/07/22/intel-agilex-soc-fpga-features-four-arm-cortex-a53-cores/ `[secondary]`
- I-Series (AGI 022, AGI 027): **2.2M / 2.7M logic elements**, up to **112 Gbps** transceivers, 3× R-Tile PCIe **Gen5 x16** hard IP, 9.4–11.8 TFLOPS SP `[official]`
- M-Series: **in production and shipping worldwide** as of April 2025, expected lifecycle **to 2035** `[vendor-reported]` — source: https://www.businesswire.com/news/home/20250401117009/en/Altera-Starts-Production-Shipments-of-Industrys-Highest-Memory-Bandwidth-FPGA `[vendor-reported]`
- M-Series headline: up to **32 GB in-package HBM2E**, **820 GB/s** peak bandwidth, NoC memory functions, hardened PCIe 5.0 / **CXL 2.0** / 400G Ethernet, transceivers up to **116 Gbps** ("highest of any FPGA provider" — vendor claim) `[vendor-reported]`
- Distributor reference prices (single-digit quantities, Hong Kong broker listings, **not** OEM MSRP): AGFA027R24C3I3V ~**US$20,462.83**/3pcs; AGFA027R25A1E1V ~**US$37,789.27**/3pcs; AGFB027R24C3E4X ~**US$37,490.52**/3pcs — treat as broker snapshots only `[secondary]`
- IP/tooling note: Serial Lite IV FPGA IP v5.5.2 validated against **Quartus Prime 25.1** (release 2025.04.07), up to 56 Gbps/lane PAM4 ×8 or 28 Gbps NRZ ×16 `[official]` — source: https://manuals.plus/m/dc40cc28e78b5d298c01f413fa9226b4e5a8bab96fc3c9fb09f78ed546d909d7_optim.pdf `[secondary]`
