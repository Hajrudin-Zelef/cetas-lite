## AMD EPYC™ 9004 Series Processors

Discover the world's most powerful server CPU.<sup>1</sup>

4th Gen AMD EPYC™ processors transform data center processor capabilities, delivering exceptional performance, energy efficiency, and the best TCO (total cost of ownership) across workloads.

## 4th Gen AMD EPYC™ processors feature the world's most powerful CPU<sup>1</sup>

4th Gen AMD EPYC processors are at the forefront of server processor technology, with up to 96 "Zen 4" cores based on a 5 nm process, the most powerful server cores ever produced by AMD.<sup>2</sup> These cores are supported by 1 MB of L2 cache per core and 32 MB of L3 cache per CCD, as well as 12 DDR5 channels supporting up to 12 TB of memory, CXL™ memory expansion, and PCIe® 5.0 support, delivering up to 128 lanes of high bandwidth for the latest graphics and storage technologies.

It is this increase in performance and technology that has enabled the AMD EPYC™ processor family to win more than 300 world records to date, in data management, infrastructure, business applications, and HPC workloads.<sup>3</sup>

Compared to previous generation AMD EPYC processors and competing products, servers powered by 4th Gen AMD EPYC™ 9654 processors deliver up to 3x higher leading cloud performance, up to 2.5x higher leading HPC performance, and up to 2.9x higher leading business performance.<sup>4,5,6</sup>

## Performance without the energy price

4th Gen AMD EPYC processors don't just deliver exceptional performance in handling nearly all workloads run by a server; in addition, they accomplish these tasks while improving energy efficiency measurably compared to the previous generation and competing products.

In fact, 4th Gen AMD EPYC processors power the most energy-efficient x86 servers.

Regarding performance-per-watt improvements in integer, floating-point, and NLP throughput compute performance, these new 64-core AMD EPYC™ 9534 processors deliver results up to 2.7x higher than previous generation AMD EPYC products with a similar number of cores.<sup>7</sup>

All of this translates into a server processor that delivers reduced power consumption, lower energy costs, and increased performance per server—all essential generational improvements for customers deploying large-scale server infrastructure.

## AMD EPYC™ Processor Security: We help you protect your data

One of the fundamental pillars of a successful server solution is adequate security. Those discovering the AMD EPYC™ processor platform will appreciate the robust ecosystem of security features that AMD has built in from the start.

AMD Infinity Guard includes multiple layers of security features, from silicon-level security features with AMD Secure Processor, to modern container security features and memory encryption systems that help protect data even before the system boots.<sup>8</sup>

Building on the cutting-edge security features of AMD Infinity Guard, 4th Gen AMD EPYC processors add enhanced advanced features such as 256-bit AES-XTS encryption and Secure Multi-Key Encryption (SMKE) that allows hypervisors to selectively encrypt address space ranges on connected CXL™ memory. This enables software encryption features to work seamlessly with connected CXL memory. You can further leverage the growing confidential computing ecosystem that focuses on solving the unique security challenges related to migrating sensitive applications and data by encrypting data in use, in cloud and virtualization environments. Learn more about AMD Infinity Guard and the technologies used to protect customer processes and data.

Ultimately, 4th Gen AMD EPYC processors provide a powerful, efficient, and secure environment for a whole range of workloads run in the data center, surpassing the AMD and competing products available today and helping to reduce operating costs.
