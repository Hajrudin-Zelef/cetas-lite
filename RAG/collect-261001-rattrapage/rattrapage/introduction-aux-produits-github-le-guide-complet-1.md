# introduction-aux-produits-github-le-guide-complet

Cours

Des développeurs du monde entier utilisent GitHub pour collaborer, gérer leur code et accélérer la réalisation de leurs projets. Dans cet article, nous passons en revue les différents produits GitHub, des offres gratuites aux solutions entreprise. Nous mettrons en avant des outils comme GitHub Desktop et GitHub Actions qui dopent la productivité et vous donnerons les repères nécessaires pour choisir l’offre la plus adaptée à vos besoins.

Ce guide vous aide également à vous préparer à la certification GitHub Foundations, une certification d’introduction proposée par GitHub. Si vous débutez avec Git ou GitHub, le futur parcours GitHub Fundamentals de DataCamp sera un excellent point de départ. Ce parcours vous donnera les compétences nécessaires pour utiliser GitHub et Git sur des projets de data science et d’analytique. Enfin, vous pouvez suivre notre cours Foundations of Git pour assimiler les bases.

## Introduction à GitHub et à son écosystème

Beaucoup connaissent GitHub comme une plateforme d’hébergement de code, mais GitHub est bien plus que cela. C’est un rouage central du cycle de développement logiciel, car il prend en charge le contrôle de version, clé pour collaborer sur des projets. Voici un tour d’horizon des principaux produits GitHub, conçus pour couvrir la majorité des besoins.

- GitHub Free : idéal pour les développeurs individuels ou les petites équipes, avec des dépôts publics et privés illimités et des outils de collaboration de base.
- GitHub Pro : ajoute des fonctionnalités avancées comme les insights sur les dépôts et du stockage supplémentaire, parfait pour les développeurs expérimentés en quête de capacités étendues.
- GitHub Team : cette offre renforce la collaboration d’équipe avec, par exemple, plusieurs réviseurs sur les pull requests et des outils avancés de gestion de projet.
- GitHub Enterprise : destinée aux grandes organisations, avec des fonctions avancées de sécurité et de conformité, ainsi que des options de déploiement flexibles comme GitHub Enterprise Cloud et GitHub Enterprise Server.

GitHub propose également des outils complémentaires tels que GitHub Desktop, GitHub Mobile et GitHub Actions, pensés pour des utilisateurs exigeants souhaitant maximiser leur productivité.

## Aperçu des types de comptes et des forfaits GitHub

GitHub propose différents types de comptes, avec des ensembles de fonctionnalités adaptés à divers niveaux de collaboration et de gestion de projet. Il vous guidera via quelques questions pour déterminer si un compte Personnel, Organization ou Enterprise répond le mieux à vos besoins.

### Comptes personnels

Les comptes personnels conviennent parfaitement aux utilisateurs individuels, comme les freelances ou les étudiants, qui cherchent un moyen simple de gérer leurs projets. Ils donnent accès à un nombre illimité de dépôts publics et privés. Des outils de collaboration de base permettent de légères interactions en équipe, et GitHub Pages offre la possibilité d’héberger des sites web simples directement depuis vos dépôts. Les comptes personnels se déclinent en deux offres, GitHub Free ou GitHub Pro :

#### GitHub Free

Le plan GitHub Free est disponible pour les comptes personnels et organisationnels. Il fournit l’essentiel, notamment des dépôts publics et privés illimités, le support communautaire GitHub et des capacités de base pour GitHub Actions. Ce plan est idéal pour les particuliers et les petites équipes qui débutent avec le contrôle de version et le code collaboratif. Il permet d’héberger des projets, de collaborer et d’automatiser des workflows avec GitHub Actions, mais avec des ressources limitées.

#### GitHub Pro

GitHub Pro s’adresse aux développeurs individuels qui ont besoin de fonctionnalités avancées pour piloter leurs projets. Outre ce que propose GitHub Free, les utilisateurs Pro bénéficient d’insights avancés sur les dépôts, de minutes supplémentaires GitHub Actions et de plus de stockage pour GitHub Codespaces. Ce plan convient aux développeurs souhaitant aller plus loin dans l’analyse de leurs projets et qui ont besoin de ressources accrues pour leurs pipelines CI/CD et leurs environnements de développement cloud.

### Comptes Organization et Enterprise

Deux autres types de comptes offrent des fonctionnalités renforcées pour gérer les équipes et les projets : les comptes organization et les comptes enterprise. Les comptes organization proposent des contrôles d’accès par rôles, plusieurs réviseurs sur les pull requests et une facturation centralisée. Les comptes enterprise visent les grandes entreprises, avec des mesures de sécurité avancées comme l’authentification unique (SSO), des journaux d’audit et des options de déploiement flexibles. Ces comptes demandent plus de ressources et d’administration, ceux d’entreprise offrant le niveau de contrôle et de sécurité le plus élevé pour les opérations à grande échelle.

#### GitHub Team

Le plan GitHub Team est idéal pour les organisations qui ont besoin de fonctionnalités de collaboration renforcées. Il s’appuie sur GitHub Free en ajoutant des outils qui optimisent les workflows d’équipe, comme plusieurs réviseurs pour les pull requests, des rappels d’équipe et des graphiques d’insights sur les dépôts. Ce plan convient aux entreprises qui doivent coordonner le travail de plusieurs développeurs tout en gardant une vision d’ensemble de l’avancement.

#### GitHub Enterprise

GitHub Enterprise est l’offre la plus avancée, avec des contrôles supplémentaires de sécurité, de conformité et de déploiement. Elle s’adresse aux grandes organisations qui exigent un niveau de maîtrise élevé de leurs processus de développement. Les clients Enterprise peuvent opter pour GitHub Enterprise Cloud ou GitHub Enterprise Server, selon leurs besoins de déploiement. Cette offre inclut des fonctions avancées comme l’authentification unique (SSO), des journaux d’audit et un support dédié, ce qui la rend idéale pour les organisations soumises à des exigences réglementaires strictes.

À propos de GitHub Enterprise, il faut également mentionner les comptes utilisateurs gérés. Si vous faites partie d’un compte enterprise, vous utilisez probablement un compte géré, ce qui implique de vous connecter pour accéder aux dépôts de votre organisation. Les entreprises souhaitent en effet garder la main sur l’activité des utilisateurs. Vous pouvez toujours créer des dépôts privés, mais votre capacité à publier en public ou à contribuer hors du réseau de l’entreprise sera restreinte, ce qui est logique au vu des enjeux de confidentialité.
