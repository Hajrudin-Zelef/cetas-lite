## Les outils complémentaires de GitHub

En plus de ses produits phares, GitHub propose plusieurs outils auxiliaires qui accompagnent les développeurs. Ils facilitent la gestion des dépôts, la collaboration et le suivi des projets, que vous voyagiez ou travailliez à distance.

*GitHub Desktop et GitHub Mobile. Image : Napkin.Ai*

### GitHub Desktop

GitHub Desktop est une application conviviale qui simplifie la gestion locale de vos dépôts. Son interface graphique permet de gérer Git et les workflows GitHub sans passer par la ligne de commande. Avec GitHub Desktop, vous pouvez cloner des dépôts, créer des branches, valider des changements et pousser des mises à jour en quelques clics. Cet outil est particulièrement utile pour celles et ceux qui préfèrent une approche visuelle de la gestion de code, car il évite les commandes Git complexes tout en offrant une solide couverture fonctionnelle.

### GitHub Mobile

GitHub Mobile vous permet de rester connecté à vos projets où que vous soyez. Vous pouvez réaliser la plupart des actions clés directement depuis votre téléphone, comme relire du code ou fusionner des pull requests. Cela dit, GitHub Mobile ne remplace pas votre environnement de travail principal : c’est plutôt un complément bienvenu. Il est surtout précieux pour rester attentif aux notifications importantes et résoudre rapidement les problèmes, puisque votre téléphone vous accompagne partout. ## Facturation, licences et notifications sur GitHub

GitHub propose des modèles de facturation à l’abonnement et à l’usage, adaptés à des besoins et des tailles de projets variés.

### Structure de facturation

La facturation GitHub se décline en deux modes principaux : à l’abonnement et à l’usage.

- Facturation à l’abonnement : ce modèle couvre les plans GitHub Free, Pro, Team et Enterprise, chacun avec un coût mensuel ou annuel fixe. Free convient aux besoins basiques, tandis que Pro ajoute des fonctionnalités à un tarif supérieur. Team propose des outils collaboratifs au prix par utilisateur, et Enterprise s’adresse aux grandes organisations avec des fonctions avancées de sécurité et de conformité. Les licences Enterprise sont généralement basées sur le nombre d’utilisateurs, avec un modèle à la consommation récemment introduit qui s’ajuste à l’usage.
- Facturation à l’usage : ce modèle s’applique à des services comme GitHub Actions, GitHub Packages et GitHub Codespaces. Bien que des quotas gratuits soient inclus, l’usage au-delà entraîne des coûts supplémentaires. Par exemple, GitHub Actions permet d’automatiser des workflows avec des minutes gratuites, mais l’excédent est facturé. De même, GitHub Packages et Codespaces facturent le stockage et le temps de calcul dépassant les quotas.

### Maîtriser les coûts

Pour mieux piloter les dépenses, GitHub permet aux organisations de fixer des plafonds de consommation pour Actions, Packages et Codespaces. Ces limites empêchent de dépasser un budget donné et évitent les surprises. GitHub fournit aussi des rapports détaillés d’usage et un tableau de bord de facturation, ce qui aide à suivre les dépenses de près et à rester dans l’enveloppe prévue.

### Gérer les notifications et abonnements

Les notifications GitHub sont extrêmement utiles. Elles vous informent de tout changement important apporté à votre dépôt. Comme il est essentiel de rester au courant dans un projet collaboratif, GitHub propose plusieurs options pour les gérer.

Vous pouvez recevoir des notifications via l’interface web, par e‑mail ou via GitHub Mobile, le tout synchronisé. De plus, vous pouvez les personnaliser pour ne voir que ce qui vous importe. Si, par exemple, vous souhaitez suivre les pull requests mais pas l’animation des discussions, maintenez les notifications sur les pull requests et mettez les conversations en sourdine.

Vous pouvez aussi configurer des filtres e‑mail ou choisir d’être alerté pour des événements spécifiques comme l’exécution de workflows ou les alertes de sécurité. Les notifications sont tellement pratiques sur GitHub que beaucoup les utilisent comme outil de triage : vous pouvez marquer certaines notifications comme « Terminé » ou en enregistrer d’autres pour les traiter plus tard.

## Questions fréquentes sur GitHub

### GitHub est-il gratuit ?

**GitHub propose des offres gratuites et payantes.** 

### Qui doit utiliser GitHub Team ?

**GitHub Team est conçu pour les organisations qui ont besoin de fonctionnalités de collaboration avancées, comme plusieurs réviseurs et des outils de gestion de projet évolués.**

### Quelles certifications GitHub propose-t-il ?

**Il existe plusieurs certifications GitHub, mais la plus fondamentale est GitHub Foundations. Elle est idéale pour les débutants qui souhaitent acquérir les bases de Git et GitHub.**

### Qu’est-ce que GitHub Actions ?

**GitHub Actions automatise des workflows tels que la construction, les tests et le déploiement du code.**

### Les utilisateurs gérés peuvent-ils accéder aux dépôts personnels ?

**Non, les utilisateurs gérés n’ont pas accès aux dépôts personnels. Ils ne peuvent accéder qu’aux dépôts et ressources de l’organisation enterprise.**
