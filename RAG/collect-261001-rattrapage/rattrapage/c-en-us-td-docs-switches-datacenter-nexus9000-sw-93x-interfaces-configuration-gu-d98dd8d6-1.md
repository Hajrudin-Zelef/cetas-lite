# c-en-us-td-docs-switches-datacenter-nexus9000-sw-93x-interfaces-configuration-gu-d98dd8d6

Information About Access and Trunk Interfaces
Access and trunk interfaces are Layer 2 port types used to carry VLAN traffic on Cisco Nexus 9000 Series switches.
- 
                                 
                                 Access ports carry traffic for a single VLAN.
- 
                                 
                                 Trunk ports carry traffic for multiple VLANs simultaneously using IEEE 802.1Q encapsulation.
Additional Information
| Note | See the Cisco Nexus 9000 Series NX-OS High Availability and Redundancy Guide for complete information on high-availability features. | 
| Note | The device supports only IEEE 802.1Q-type VLAN trunk encapsulation. |
