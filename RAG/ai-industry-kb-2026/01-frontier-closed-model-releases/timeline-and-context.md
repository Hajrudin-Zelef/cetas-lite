# Timeline and context

- **OpenAI** — Sam Altman (CEO; confirmed Spud pretraining completion to employees March 24); Greg Brockman (president; Big Technology podcast: Spud = "two years of research," "big model feel"). Frontier line: GPT-5.4 (Mar 5) → GPT-5.5 "Spud" (GA May) → GPT-5.6 Sol/Terra/Luna (govt preview Jun 25–26; GA Jul 9). The Information first reported the Spud codename.
- **Anthropic** — Dario Amodei (CEO; India AI Impact Summit Feb 17 for the Sonnet 4.6 launch; first Bengaluru office; India = second-largest market). Frontier line: Opus 4.6 (Feb 5) → Sonnet 4.6 (Feb 17) → Opus 4.7 (Apr 16) → Opus 4.8 (May 28) → Fable 5/Mythos 5 (Jun 9; export-controlled Jun 12–30) → Sonnet 5 (Jun 30) → Opus 5 (Jul 24) → Fable 5.1/Mythos 5.1 (Sep 1).
- **xAI** — Elon Musk (announced Grok 4.5 private beta June 28 on X; monthly-new-foundation cadence claim [UNVERIFIED]). Frontier line: Grok 4.1 (Nov 2025) → Grok 4.2/4.20 Beta (Feb 17–18, 2026) → Grok 4.5 (Jun 28 beta → Jul 9 GA) → Grok 4.6 (Aug 12) → Grok 4.7 (Sep 21, 2026). Real-world test beds: SpaceX, Tesla. Training-data collaboration: Cursor. Some press renders the company as "SpaceXAI" — no corporate confirmation; use xAI.
- **Google** — Sundar Pichai (Google I/O 2026 keynote, May 19). Gemini 3.1 Pro (Feb 19 preview); Gemini Omni (I/O unveiling; developer rollout ~Jul 1–2); Nano Banana 2 Lite (~Jul 1–2); Gemma 4 12B (Jun 3, Apache 2.0).
- **Meta (Superintelligence Labs)** — Mark Zuckerberg and Alexandr Wang (Muse Spark 1.2 launch Aug 5; open-weights "soon" announcement Aug 10). Muse Spark lineage: original (Apr 2026) → 1.1 (Jul 9) → 1.2 (Aug 5) → 1.3 (Sep 2). Muse Code terminal agent co-launched with 1.2.
- **Benchmark / index authorities**: Artificial Analysis (Intelligence Index — Opus 4.8's 61.4, Grok 4.6's 61, Fable 5's 62, Opus 5's 63, Muse Spark 1.2's 54/57, Muse Spark 1.3's 61); Epoch AI (FrontierMath custodian — confirmed fabricated DeepSeek V4 leak scores); Cursor (CursorBench; debugging-session data for Grok 4.5); Scale AI (MCP-Atlas); the LAUDE Institute + Stanford (Terminal-Bench 4.0).
- **Peripheral but dated**: Nicholas Carlini (viral Opus 4.6 demos — C compiler from 16 parallel agents, 100K lines of Rust booting Linux 6.9); Polymarket (Spud release odds); The Information (Spud codename; DeepSeek V4 pre-release reporting); Amazon (research report describing the Fable 5 jailbreak technique — the export-control trigger, per Anthropic's own account).
