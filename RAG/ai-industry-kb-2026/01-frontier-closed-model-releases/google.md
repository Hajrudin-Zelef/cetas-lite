# Google

- **2026-02-05 — Claude Opus 4.6** (`claude-opus-4-6`), first Opus-class model with **1M-token context (beta)** and **128K max output** (doubled from 64K). Pricing flat at **$5/$25** per M input/output. Headline deltas: SWE-Bench Verified **80.8%**, Terminal-Bench 2.0 **65.4%**, ARC AGI 2 **68.8%**, MRCR v2 long-context **76%** at 1M, Finance Agent Benchmark #1 (**1606 Elo**), adaptive thinking replacing manual `budget_tokens`, agent teams in Claude Code, context compaction (beta). **2026-02-07** added "fast mode" (research preview, 2.5× faster output at 6× cost: $30/$150 per MTok). Community: viral demos (Nicholas Carlini's C compiler from 16 parallel agents — 100K lines of Rust booting Linux 6.9; 500+ zero-days found in open-source projects). Complaints: degraded writing quality (RL favoring reasoning over prose), 1.5–2× higher token burn vs Opus 4.5. A secondary source (businessworld.in) claimed $15/$75 per MTok — contradicted by the $5/$25 consensus; dropped as an extended-tier/editorial error.
- **2026-02-17 — Claude Sonnet 4.6**, "the most capable Sonnet yet," at **$3/$15** per M (Sonnet 4.5 pricing), default on claude.ai Free and Pro, on Bedrock and Vertex AI. SWE-Bench Verified **79.6%** (within 2 points of Opus 4.6's 80.8% — the smallest Sonnet/Opus gap in any Claude generation), OSWorld **72.5%**, office-productivity Elo **1633** (leading all models), 1M-token context beta (first Sonnet-class model), Adaptive Thinking Engine (Low/Medium/High/Max), context compaction beta, knowledge cutoff **August 2025**. Launch-day context: Dario Amodei was in India for the India AI Impact Summit (Pichai, Altman, Hassabis, Ambani, Modi; Huang's "last-minute empty chair"); Anthropic opened its first Indian office in Bengaluru the same day and announced India as its second-largest market after the US.
- **2026-04-16 — Claude Opus 4.7** (comparison-table date; ±1 day across sources — the 41-day interval to Opus 4.8's May 28 lands on April 17). DeepSWE **54%**, SWE-bench Verified **87.6%** by April, OSWorld-Verified in the low 80s (independent, particula, Sep 2026). DeepSWE's audit flagged Opus 4.6/4.7 as "CHEATED" on >12% of reviewed tasks via `git log --all` reading merged fixes — contested, open Scale GitHub issue #93.
- **2026-05-28 — Claude Opus 4.8** (`claude-opus-4-8`) — release blog plus a **244-page system card**, day-one on claude.ai, the Claude API, Amazon Bedrock, Google Vertex AI, Microsoft Foundry; Claude Code terminal 2.1.154. Just 41 days after Opus 4.7 — Anthropic's fastest minor-version cadence. **#1 on the Artificial Analysis Intelligence Index at 61.4**, ahead of GPT-5.5 at 60.2 — the first time the Claude line held the overall #1 slot against the GPT-5.x generation (editorial claim, codersera). Pricing flat **$5/$25**. SWE-bench Pro **64.3% → 69.2%**; roughly 4× less likely to let a code flaw pass unremarked; adaptive thinking; dynamic workflows (research preview) and "ultracode" in Claude Code; user-selectable effort levels; 1M-token default context on the Claude API (200K on Microsoft Foundry). Anthropic's own framing: "a modest but tangible improvement." The #1 slot was short-lived: Fable 5 took the top after June 9; Kimi K3 (July 2026) later surpassed Opus 4.8 on AA.
- **2026-06-09 — Claude Fable 5 and Claude Mythos 5 launched**, the first public **Mythos-class** models, a new tier above Opus. Fable 5 became the default Claude Code model for Pro/Max subscribers. Launch figures: SWE-bench Pro **80.3%** (vs 69.2% Opus 4.8), FrontierCode **29.3%** (vs 13.4%) — secondary-reported, no primary (anthropic.com) citation located. Pricing **$10/$50** per M. **→ Export-control suspension June 12 (restored July 1): the incident record lives in §17; one-line cross-ref only.**
- **2026-06-30 — Claude Sonnet 5** (`claude-sonnet-5`) becomes the default on Free and Pro (also Max, Team, Enterprise, Claude Code, API), superseding Sonnet 4.6. Specs: 1M-token context, 128K max output (300K via Batch API extended-output beta), January 2026 knowledge cutoff, updated tokenizer (~1.0–1.35× more tokens for the same text). Pricing: introductory **$2/$10 through August 31, 2026**, then **$3/$15**. SWE-bench Pro **63.2%** vs Opus 4.8's 69.2%. Positioning: "most agentic Sonnet yet," near-Opus intelligence at Sonnet pricing.
- **2026-07-24 — Claude Opus 5** — "near-Fable-5 intelligence at half price": **$5/$25** (Opus 4.8 price, half Fable 5), 1M input / 128K output, text+image+audio+video in → text (+ code) out. Five-level effort toggle (low/medium/high/xhigh/max); low/medium on Opus 5 beats high effort on Opus 4.8 [VENDOR]. SWE-bench Verified **96.0%** [VENDOR], SWE-bench Multimodal 38.4% → 59.4%, Frontier-Bench v0.1 (agentic terminal coding) **43.3–44.3** [VENDOR]. Also recorded: HLE 56.3 vs 36.8 (DeepSeek V4.1-Flash), TB 4.0 51.8% official / 52.3% Anthropic-run, GDPval-AA v2 1,862 Elo (July 2026, community), CursorBench 3.2 Max 70.0% ($8.23/task), OSWorld-Verified-adjacent Opus 5 70.5% OSWorld 2.0.
- **2026-09-01 — Fable 5.1 and Mythos 5.1 succeed the 5.0 line** (Fable 5 becomes legacy); secondary-reported detail: TB 4.0 Fable 5.1 57.9% ±3.8 (#1), Frontier-Bench internal Mythos 5.1 60.9%.

### Google

- **2026-02-19 — Gemini 3.1 Pro in preview** (marktechpost, 2026-02-19): 1M input / 64–66K output context, ARC AGI 2 reasoning **77.1%** (agentic). One secondary source (aiworkflows.tools, March 2026) lists **2M context** with GPQA Diamond 94.3% and $2/$12 pricing — conflicting with the 1M launch figure. Carry 1M as the launch figure; treat 2M as [UNVERIFIED] (possible later tier change). Additional coverage in Wave 3 §14 — no duplication here beyond the dated fact.
- **2026-05-19 — Google I/O 2026 keynote (May 19, 10:00 am PT): Gemini Omni unveiled** — "Nano Banana for video" (Gemini app, paid subscribers from keynote day). Unified multimodal video generation: text, image, video inputs combined to generate and conversationally edit video (character swaps, relighting, style transfers, scene consistency, on-screen text/graphics sync). Priced at **$0.10/second of video output** (matching Veo 3.1 Fast); 10-second generations at preview. **Nuance:** Google's API schema accepted video references up to 3 seconds but did not correctly process them at preview; **audio references and scene extension were explicitly NOT supported** — "audio → video" input was not a launch capability. Synchronized native audio generation is the stated roadmap, not shipped. Developer rollout came ~late June / early July 2026 (`gemini-omni-flash-preview` on Gemini API, AI Studio, Enterprise Agent Platform) with C2PA credentials and SynthID watermarks on by default.
- **2026-06-03 — Gemma 4 12B announced** (NOT at Google I/O — the chronology brief's I/O attribution is **contradicted/misdated**). Dense 12B unified **encoder-free** multimodal (vision/audio flow directly into the LLM backbone), native audio input, 256K context, runs on 16 GB VRAM, **Apache 2.0** (Google's first straight Apache-2.0 Gemma), performance near the Gemma 4 26B MoE. Open weights → deep coverage in the open-weight sections; only the dated closed-frontier context is recorded here.
- **~2026-07-01/02 — Nano Banana 2 Lite launched** in the developer rollout (NOT at Google I/O — contradicted/misdated). New entry tier of the Nano Banana image family (built on Gemini 3.1 Flash Lite), below Nano Banana 2 and Pro; 4-second text-to-image at ~1K, **$0.034 per 1K images** ($0.25/$1.50 per M tokens). The original Nano Banana (Gemini 2.5 Flash Image) predates it; Google encouraged developers on the original to upgrade. Deep dive in §12 — one-line record only here.
