# 13. Agents & MCP
Keywords: Model Context Protocol, MCP, 97M monthly SDK downloads, spec 2026-07-28 final, stateless protocol, Agentic AI Foundation, MCP Dev Summit, official registry, Stacklok State of MCP 2026, coding agents, Claude Code, Codex, Cursor, Devin, OpenHands, LangGraph, Microsoft Agent Framework, SWE-bench, Terminal-Bench 4.0, DeepSWE, computer use, agent sandboxing, A2A, ACP, Cognition SWE-2, test-time compute, DeepSeek V4.1-Flash, benchmark trust crisis, MCP-Atlas, workload inversion

## Summary

2026 was the year the autonomous agent moved from demo to deployed infrastructure, and the Model Context Protocol (MCP) became its standard integration fabric. The consolidated record resolves two priority items. **Priority 1 — the 2026-07-28 MCP specification is FINAL**, published 2026-07-28 (RC locked 2026-05-21, RC published 2026-05-29; tier-1 SDKs shipped the same day). The protocol's own versioning page states verbatim: "The current protocol version is 2026-07-28," and now labels 2026-07-28+ implementations "modern", 2025-11-25 and earlier "legacy", dual-support ones "dual-era". The wave-2.1 RC caveat (a June-2026 standards tracker advising 2025-11-25 as current Final, researched 2026-06-10 during the RC window) is **obsolete and superseded** — the consolidation must present 2026-07-28 as Final. **Priority 2 — a wave-2 figure retraction**: wave 2's "78% of enterprise AI teams with at least one MCP-backed agent in production (April 2026 survey)" has **no traceable source and was retracted by at least one publication that carried it** (per the LLM Book 2026 edition: "Do not use it"). It is replaced by the Stacklok "State of MCP in Software 2026" survey — VERIFIED verbatim: **41% in production (29% limited + 12% broad), 30% in pilot, 29% planning or evaluating** (n=100 senior technical leaders, software cohort, report 2026-01).

The growth arc of MCP in 2026 is verified at each step. On **2026-03-25** the combined Python + TypeScript SDKs crossed **97 million monthly downloads**, a ~4,750% increase over ~2 million at the November 2024 launch — the crossing date and figure verified from a Dev Summit retrospective citing SDK registry data, corroborated by multiple independent engineering guides citing the same 97M figure for March 2026. The official registry counted **9,652 latest server records (28,959 server-version records) on 2026-05-24**; an April 2026 field report found **"over 12,000 MCP servers across 33 registries"**; the **110M/month figure is dated June 2026** (Dev Summit India reporting — "crossed 110 million SDK downloads a month"), not July as earlier drafts said. One-aggregator claims of ~500M/month remain single-sourced and methodologically divergent — **do not use**. [EDITORIAL] No source uses the exact phrase "TCP/IP moment" for the 2026-07-28 spec — the substance (the protocol's biggest breaking revision to date: stateless core) is verified, the label is the brief author's commentary. The **"USB-C of AI"** framing is a **supported synthesis**: Anthropic's own original positioning, repeated verbatim across independent 2026 engineering guides.

The institutional story is the March–April 2026 "experimentation → infrastructure" transition. **Anthropic donated MCP to the Agentic AI Foundation (AAIF), a directed fund under the Linux Foundation, in December 2025** (co-founded with Block and OpenAI; supporters incl. AWS, Google, Microsoft, Cloudflare, Bloomberg). The transition was publicly staged at the **MCP Dev Summit North America (April 2–3, 2026, New York)** — the first engineering conference organized by AAIF, 95+ sessions, speakers from Anthropic, OpenAI, AWS, Docker, Datadog, Uber, PwC and enterprises running MCP in production. AAIF/LF executive director Jim Zemlin: "AI agents are quickly moving from demos to deployed systems, and that shift demands shared infrastructure." The summit's opening keynote paired **David Soria Parra (MCP co-creator, Anthropic)** with **Nick Cooper (core protocol maintainer, OpenAI)** — joint OpenAI + Anthropic stewardship embodied, and **joint adoption CONFIRMED** (OpenAI's Agents SDK has had first-class MCP support since April 2025; ChatGPT; Nick Cooper as core maintainer presenting alongside the MCP co-creator).

The 2026-07-28 revision is the protocol's biggest breaking change: **stateless core (SEP-2567)** — the `initialize`/`initialized` handshake and the `Mcp-Session-Id` header removed; client metadata travels in `_meta` on every request; capabilities fetched via the new mandatory `server/discover` RPC; Tasks moved to an extension (SEP-2663); 12-month-minimum deprecation floor for Roots, Sampling, Logging and the legacy HTTP+SSE transport (earliest removal 2028-07-28); the first revision with a formal feature lifecycle policy and deprecated-features registry. The **adoption-lag caveat is real and material**: most deployed clients still speak 2025-06-18 or 2025-11-25 — five breaking revisions in ~20 months with a deprecation policy only formalized in the latest one. Enterprise guidance in 2026 converges on gateway-mediated, allow-listed deployment with audit logging, tool allowlisting, identity binding and human-in-the-loop approval; the 2026 enterprise roadmap (SSO-integrated auth, workload identity federation, gateway standardization) is **VERIFIED directionally**, and **config portability is downgraded to roadmap-aspiration** — a documented pain point (per-host config formats: Goose YAML vs Codex TOML), not a shipped feature. Audit trails are enterprise guidance reinforced by the EU AI Act, whose high-risk obligations became enforceable **2026-08-02**.

Parallel to the protocol story, 2026 was the year coding agents crossed from autocomplete to execution. The framework landscape: **LangGraph** (v1.0 GA 2025-10-22; ~34–39M monthly PyPI downloads mid-2026, highest of any agent framework; production users incl. Klarna, Replit, Uber, LinkedIn, Elastic, BlackRock, Cisco, JPMorgan) as the production orchestration default; **OpenAI Agents SDK** (~26,900 stars, ~10.3M monthly downloads; April 2026 overhaul adding native sandboxing, sub-agents, Codex-style filesystem tools, first-class MCP support); **Microsoft Agent Framework** (AutoGen + Semantic Kernel merged, v1.0 GA April 2026, default for .NET/Azure-native teams); **Claude Code** (fastest-growing Cursor competitor; background subagents by default, nesting to 5 levels, `/effort ultracode` fanning out tens-to-hundreds of subagents); **Codex** (April 16, 2026 "Codex for (almost) everything" — Background Computer Use, parallel multi-agent execution, 90+ plugins; vendor claim 3M weekly active developers); **Cursor** ($4B annualized revenue June 2026, ~2M+ DAU, 64–67% of Fortune 500; [UNVERIFIED] $60B SpaceX/xAI acquisition deal reported June 16, 2026, acquirer identity inconsistent across sources — do not assert); **Cognition/Devin** (Series E $2B at $48B valuation Sept 8, 2026, run-rate revenue ~$900M, vendor-reported); **GitHub Copilot** (coding agent, Automations GA 2026-06-02, Copilot app at Build 2026, Copilot CLI with four built-in agents); **Google Jules** (GA since Aug 6, 2025; 140,000+ public code improvements in beta); **Replit Agent 4** (Mar 2026, parallel subagents with auto-merge); **OpenHands** (ex-OpenDevin, 80,000–87,000+ stars, EventStream + CodeAct architecture).
