# fr-review-ubiquiti-enterprise-nas-review-16-bays-dual-25gbe-and-zfs-for-3999-25cfd5e9

The decision comes down to software. Businesses using Synology or QNAP application ecosystems (containers, surveillance, turnkey backup suites) will find UniFi Drive spartan in comparison. Virtualization designers will need to take into account the iSCSI sequential read anomaly and the synchronous write penalty before opting for this storage solution. But that is not really the target audience for this enclosure. For SMBs with a medium-to-large UniFi deployment that need simple, reliable file and block storage, managed from their usual console, with snapshots, replication, cloud backup, and directory integration included, with no license fees, the ENAS is the most performant storage solution Ubiquiti offers, and the first that established players must take seriously. Given the pace of UniFi Drive updates since we received our unit, we expect the software gap to continue narrowing, and we will reevaluate the platform as immutable snapshots and expansion bays become available.
