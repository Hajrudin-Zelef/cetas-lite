# fr-review-storage-innovation-in-action-transforming-film-and-tv-workflows-89d97f09

<!-- source: https://www.storagereview.com/fr/review/storage-innovation-in-action-transforming-film-and-tv-workflows -->

NAB 2024 opened with flair, as tens of thousands of attendees gathered at the Las Vegas Convention Center to discover the latest technologies for media and entertainment professionals. Over the many years of NAB, one thing has never changed: digital files are becoming increasingly important, and teams need to access them faster, both in the data center and in the field. Fortunately, technology has made crucial advances, such as 61.44 TB SSDs, which can solve the complexities related to M&E workloads.
Working on a film or television show imposes a level of stress on storage different from what is typically seen in the data center. Teams on set need instant access to raw footage for playback, real-time visual effects pre-visualization, continuity checking, and transcoding. The latter is the most storage-intensive. It is not uncommon to process footage faster than real time while offloading new footage from cameras. Then, these large files and their smaller proxy counterparts must be transported to a post facility where they can be ingested into long-term storage systems and made available to the post-production team.
CheetahRAID RAPTOR for on-set data storage
To support creative professionals in this mission, CheetahRAID designed the ideal edge server for data storage on film sets. The CheetahRAID RAPTOR is a compact and rugged 2U server, equipped with three drive bays each capable of holding four SSDs. After shooting, the bays can be removed and shipped to a post-production studio for rapid processing. For this project, each bay contains four 61.44 TB Solidigm P5336 SSDs, offering exceptional density. This represents nearly 250 TB of raw flash capacity per bay.
The solution leverages the Graid SR-1010 RAID card, based on a GPU, and its associated software for ultra-fast storage access. This is crucial because the Graid card offloads most RAID management from the server's processor, freeing it for more critical tasks. Since the CheetahRAID server is equipped with an AMD EPYC 7003 processor, it is essential that it remains available to run applications.
The server is equipped with an NVIDIA 100GbE network card allowing storage to be shared with professional workstations. For this test, we use two HP Z4 Rack G5 workstations, each equipped with a 100GbE network card connected directly to the server. This should allow us to achieve a theoretical throughput of approximately 12.5 GB/s per workstation. Remarkably, nearly three-quarters of a petabyte of storage is available to each system.
However, to reliably deliver such speed to each workstation, a robust protocol must be in place, capable of handling not only data movement, but data movement at this scale. For this, the system uses Tuxera's Fusion File Share. Fusion File Share allows the Linux-based CheetahRAID storage server to provide SMB shares to workstations. It is significantly faster than the original Linux implementation of the SMB server, Samba. And it's not just about raw throughput; the editing process is much more sensitive to latency, where even minor issues can crash editing programs.
Why Fusion File Share?
Tuxera's Fusion File Share is a high-performance, scalable distributed file system that enables access to unstructured or file-based data over a network. It supports Microsoft's Server Message Block (SMB) protocol for public cloud Platform as a Service (PaaS) offerings, software-defined storage (SDS) solutions, high-performance computing (HPC) applications, and enterprise network-attached storage (NAS). Fusion has all the security features and updated SMBs to meet demanding organizational needs.
Tuxera's Fusion File Share stands out as an alternative to traditional SMB server solutions like Samba, designed to focus on high performance and scalability. Its modular and multithreaded architecture improves I/O throughput, minimizes CPU usage, reduces memory footprint, and supports simultaneous management of multiple connections. By leveraging SMB multicasting, compression, and SMB over RDMA (Remote Direct Memory Access), Fusion effectively eliminates common bottlenecks, delivering a solution where high throughput, low latency, and efficient resource utilization are paramount. RDMA over Converged Ethernet (RoCE), or SMB Direct, also allows data packets to entirely bypass CPU processing, further reducing latency and CPU load for improved overall performance.
Fusion's scalability is one of its key strengths, with its file share evolution functionality allowing dynamic adjustment of SMB nodes and file servers to meet changing business needs. This is complemented by a robust fault tolerance framework, incorporating seamless failover and continuous availability to ensure uninterrupted service, even during server failures or maintenance activities. Additionally, Fusion's support for the latest SMB 3.1.1 protocol, as well as earlier versions, ensures broad compatibility and interoperability across various network settings.
Fusion File Share offers a streamlined and secure approach to data management. It facilitates capacity planning with quota support, provides detailed user audits and access logs, and enables dynamic share configurations without system restarts. It supports multiple authentication mechanisms, including Kerberos, LDAP, and NTLM, and integrates seamlessly with Windows ACL and Active Directory for enhanced security and ease of management. This comprehensive set of features positions Tuxera's Fusion as a highly reliable and efficient choice for organizations seeking superior performance and scalability from their SMB server solutions.
Samba and Fusion File Share Performance
The CheetahRAID RAPTOR storage server is built around a single-socket AMD EPYC Gen3 motherboard, running a 24-core 7443P processor with 256 GB of DDR4 RAM. The server has three cartridges that host four-SSD storage (12 SSDs total). Inside each cartridge are 4 Solidigm P5336 61.44 TB SSDs. These drives use direct NVMe connections to the motherboard via native NVMe slots.
The server uses Graid SupremeRAID SR-1010 for RAID management. To route data over the network, there is a dual-port NVIDIA Connect-X 6 Dx 100GbE card. This card offers up to 200 GB of combined bandwidth across both ports, giving us up to 20 GB/s in and out of the box across our entire network fabric. The storage server runs Ubuntu 22.04.4 LTS.
We used two HP Z4 Rack G5 workstations to act as loaders in our test environment. Each system had Intel Xeon W5-2465X 16-core processors and 128 GB of DDR5 RAM. They also feature NVIDIA RTX 5000 Ada GPUs and NVIDIA ConnectX-6 Dx 100GbE network cards to make them video editing powerhouses. The systems were configured with Windows Server 2022. It should be noted that HP does not directly support Windows Server and 100GbE network cards, but neither posed any issues during these tests.
The high-speed network fabric connects them to the CheetahRAID Raptor via 100 GbE links, providing each client with a 10 GB/s link to shared storage. With 12 Solidigm P5336 61.44 TB QLC SSDs in a Graid storage pool, we could share a massive 613 TB volume with each host.
To measure the benefits of Tuxera's Fusion software, we compared the bandwidth and latency of 1 MB sequential read and write for each client interacting simultaneously with the CheetahRAID storage host. We used four FIO jobs on each client, each measuring the performance of a 50 GB file. In total, this equates to a 400 GB footprint. Our baseline was measured using Samba version 4.15.13 compared to Fusion over TCP and again with Fusion leveraging RDMA offload.
The baseline Samba read bandwidth on each HP Z4 Rack G5 workstation measured 4 GB/s and 3.8 GB/s, for a total of 7.8 GB/s. In a sequential write workload, we measured 2.4 GB/s and 2.6 GB/s for a total of 5 GB/s. Average read latency measured 17.23 ms, with average write latency of 26.6 ms.
Switching to Tuxera's Fusion software had a considerable impact, with no changes needed on the client side. Looking at the TCP protocol, we measured 11.1 GB/s and 11.1 GB/s for each client, giving us 22.2 GB/s of read bandwidth. This was the limit of the 100 GbE connection to each host. For write bandwidth, we measured 5.7 GB/s and 5.8 GB/s, giving us a total of 11.5 GB/s. Read latency averaged 6 ms while write latency was 11.65 ms.
In addition to TCP, Tuxera's Fusion File Share also supports RDMA. We measured the Fusion RDMA protocol, which gave us read bandwidth measuring 11.6 GB/s and 11.6 GB/s for each host, or 23.2 GB/s. Write bandwidth was 5 GB/s and 5.2 GB/s, for a total of 10.2 GB/s. Read latency in this configuration was 5.8 ms, while write latency was 13.2 ms.
Comparing Samba to Fusion showed huge gains for Windows clients. Read bandwidth was nearly 3x higher, with latency only 33% of that offered by Samba. Write bandwidth was also 2.3x higher, with latency only 44% of that measured with Samba.

Huge SSDs keep pace with M&E
Massive SSDs like Solidigm's 61.44 TB P5336 bring substantial benefits to the media and entertainment sectors, where speed and reliability are crucial for handling large files such as high-definition video, complex graphics, and extended audio tracks. Unlike traditional Hard Disk Drives (HDDs), SSDs offer faster data access times, higher read/write speeds, and a greater number of I/O operations per second. This performance advantage enables more efficient editing, rendering, and processing workflows, significantly reducing the time needed to load and use large media files. The absence of moving parts in SSDs improves their reliability and durability, making them less susceptible to mechanical failures and data loss (critical issues when it comes to valuable media content).
The adoption of dense SSDs in media production and post-production environments streamlines workflows, enabling real-time editing, color grading, and effects processing without compromising quality or efficiency. These drives can seamlessly handle multiple 4K video streams, eliminating the need for proxy files or low-resolution placeholders. Additionally, the compact format of SSDs, combined with their high storage capacities, simplifies data management by allowing entire projects to be stored on a single drive or minimal array, facilitating access to and management of large volumes of data.
Beyond performance and capacity benefits, massive SSDs contribute to a more conducive production environment through their silent operation, low heat output, and energy efficiency. These features are particularly useful in densely packed or mobile editing suites, where noise reduction and cooling are constant concerns. The energy efficiency of SSDs not only reduces operational costs but also helps create a cooler and quieter workspace, improving overall productivity and comfort for media professionals. Essentially, massive SSDs are transforming the media and entertainment landscape, enabling faster, more reliable, and more efficient production processes capable of keeping pace with the growing demand for high-quality digital content.

Conclusion
Tuxera's Fusion File Share sequential speeds are ideal for quickly downloading and verifying footage, especially when shooting with many cameras. Fast storage is not unfamiliar in on-set use, and speed alone won't impress many, but the ability to be networked and offload multiple systems simultaneously without slowing down is a particular workflow in which Tuxera Fusion excels.
Most of the time on set, the limiting factor is not storage but the camera media, and this bottleneck becomes problematic, especially when you start having double-digit camera counts. It is not uncommon for multiple systems to offload multiple cards simultaneously to independent drives, which must then be consolidated either on set to an identical pair of master drives, or at the post relay on their servers.
The ability to network many systems to the same Tuxera Fusion storage pool and offload them simultaneously without slowing down constitutes a huge time savings. More importantly, a standard NAS would struggle to efficiently scale this shared storage with many clients if it used Samba, enabling offloading, transcoding, management, review, and quality control to all happen simultaneously.
While we have discussed the benefits offered by this solution on set, it is also essential to understand that all of this is very low in complexity. The CheetahRAID server, Solidigm QLC SSDs, Graid Technologies RAID management, and Tuxera protocol are all very easy to configure in a basic Linux installation. The entire solution is assembled in minutes, not hours, and brings together the best technologies for M&E professionals.
