# fr-review-artesca-veeam-unified-software-appliance-74a26655

The "Platform" page provides information about the server on which you chose to run the ARTESCA+ Veeam unified software appliance. The "Dashboard" tab displays service status, several activity graphs, and an "Advanced Metrics" button. Clicking this button opens the Grafana monitoring dashboard integrated into the appliance, which presents statistics on resource usage and server activity. This feature is particularly useful for organizations wanting to collect data on backup performance, network bandwidth usage, and reliability. It requires no additional installation or configuration during initial setup.
We have worked extensively with Grafana dashboards for storage solutions over the years. One of the most interesting aspects is that this service runs directly on the appliance. We are used to vendors offering Grafana dashboards that can be integrated into existing environments. ARTESCA goes further by providing an operational and deployed instance, ready to use for its customers. This is a considerable asset for monitoring services.
The "Nodes" tab allows you to configure additional ARTESCA+ nodes for redundancy, supporting 1, 3, or 6-node architectures. It is important to note that the ARTESCA+ Veeam solution is currently single-node; we are highlighting the broader ARTESCA features for reference. The "Volumes" tab allows administrators to create, modify, or delete volumes on connected nodes.
After installation, the volumes necessary for the operation of the ARTESCA+ Veeam unified software appliance are visible.
The "Storage Services" page allows you to manage the ARTESCA+ cluster and the individual data disks of the nodes. The "Expand Cluster" button allows you to add or remove nodes. When a node is selected, all its data disks are displayed. Faulty disks can be safely removed and replaced by clicking the "Unmount faulty disk" button. It is also possible to add disks by clicking the "Mount X new disks" button, where X represents the number of unused disks connected to the node. Like the "Dashboard" tab on the "Platform" page, the "Advanced Metrics" button opens Grafana and displays detailed statistics for the data disks of the selected node.
The next page is "Data Management." This view presents tabs titled "Accounts," "Data Explorer," "Workflows," "Locations," and "Data Services." Each tab controls functions essential to the operation of the ARTESCA+ Veeam unified software appliance.
If you use Microsoft's Azure cloud platform to store data, you are probably already familiar with the concept of storage "accounts." An account is a namespace containing one or more buckets, which serve as a repository for data objects, such as virtual machine backups. The contents of these buckets are visible by clicking on the "Data Explorer" tab and selecting the relevant bucket. This tab allows you to create, empty, delete, and modify the capacity of buckets. The "Workflows" tab allows you to configure automated replication, expiration, and transition actions (moving the contents of a bucket to another location, often used for archiving).
The "Locations" tab allows you to add additional internal or external repositories, including Amazon S3, Google Cloud Storage, Microsoft Azure Blob Storage, etc. Connected locations are listed on the page, and you can add new ones using the "Create Location" button on the right.
The "Data Services" tab displays the internal S3 endpoints used by the integrated Veeam instance. Unlike other ARTESCA deployment options that expose S3 endpoints via this tab, the ARTESCA+ Veeam unified software appliance does not support the creation of additional data services, thus ensuring a maximum level of security.
The last configuration element of the management interface is the "Alerts" page. This records current and past alerts, including those related to operating system updates, disks, services, nodes, and warnings about available space in volumes and the file system. You can also configure alert sending by email using the "Email Notification Configuration" button and the associated wizard.
Thanks to its intuitive user interface, the ARTESCA+ Veeam unified software can be easily configured to meet the backup and archiving needs of companies and organizations in various sectors, and is further enhanced by Veeam's ever-growing compatibility.
ARTESCA+ Veeam
The interface of the ARTESCA+ Veeam unified software appliance consists of the integrated Veeam instance. Running on KubeVirt, this Windows Server virtual machine, equipped with Veeam Backup & Replication, supports backing up virtual machines from various hypervisors, including Proxmox VE, Microsoft Hyper-V, VMware vSphere (ESXi/vCenter), Nutanix AHV, Oracle Linux Virtualization Manager, and many others. Faced with many customers migrating to virtualization solutions other than VMware-based ones, Veeam plans to soon extend support to other popular hypervisors, such as XCP-NG, HPE Morpheus VM Essentials, Citrix XenServer, and Red Hat OpenShift Virtualization. See the latest news regarding Veeam Data Platform v13.
The benefits of a unified software appliance
Veeam integration improves the performance, efficiency, and security of the Scality software appliance. Data transfer between Veeam and the S3 storage repository, provided by ARTESCA+, takes place internally via a virtualized network. This approach eliminates the need to duplicate external network traffic between hypervisors, data sources, Veeam, and the storage repository. It also helps protect the S3 bucket against attacks, thereby reducing the solution's attack surface.
To configure the S3 bucket used by the integrated Veeam virtual machine, log in to the ARTESCA+ web interface and go to the "Accounts" tab on the "Data Management" page. Then click the "Start Veeam VBR Wizard" button, which will display a wizard for configuring a storage account and bucket.
In our lab, the integrated Veeam wizard deployed a functional and immutable repository in a few minutes. It created the ARTESCA account, enabled versioning and object lock on the bucket, configured SOSAPI capacity reporting, and provided us with the endpoint, region, and keys needed for Veeam. Thanks to the internal communication between Veeam and the S3 service, no resources were exposed on the network and no DNS configuration was required, thus avoiding the usual back-and-forth between storage and backup teams. The process is simple for generalist IT professionals and, based on our experience, proved extremely reliable while retaining advanced control options.
Once the initial software configuration is complete, the Windows Server instance running Veeam Backup & Replication is accessible via RDP (Remote Desktop Protocol) or VNC. Veeam must then be connected to the ARTESCA+ S3 storage bucket using the "Backup Repositories" tab on the "Backup Infrastructure" page. Right-click on the tab, then select "Add Backup Repository" to add the previously created S3 bucket.
Select "Object Storage" in the list of backup repository types, then choose "S3 Compatible" on the next two pages. A wizard will then appear, prompting you to enter the connection information for the S3 bucket you created. The "Service Point" is found in the "Data Services" tab of the "Data Management" page in the ARTESCA+ web interface (in our case, it was "s3.artesca-plus-veeam.local"). Enter the region (available in the "Locations" tab) and credentials, select the previously created bucket and folder, then configure the "Mount Server" to be the Veeam server integrated into the ARTESCA+ Veeam unified software appliance. You can also set additional parameters, such as an object limit and whether to enable instant recovery with the vPower NFS service.
Veeam is now ready to connect to a data source or hypervisor to start backups.
