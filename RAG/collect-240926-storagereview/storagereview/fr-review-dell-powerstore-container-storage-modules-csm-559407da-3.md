# fr-review-dell-powerstore-container-storage-modules-csm-559407da

Dell recognizes the continued position and importance of containers and K8s in today's modern data center. As such, Dell has added new features to the proven PowerStore storage appliance range to meet these needs. These features allow modern workloads to have many of the same storage features as traditional workloads. But Dell doesn't just rest on its laurels; it continues to enable its CSI/CSM integration and will soon add application mobility modules (currently in technical preview), encryption, and volume placement to its offerings.
Among these solutions, application mobility seems the most interesting to us because it allows Kubernetes administrators to clone their stateful application workloads and data to other clusters, on-premises or in the cloud. Application mobility uses Velero and its Restic integration to copy application metadata and data to object storage.
Dell's work allows application developers and DevOps teams to manage more provisioning and maintenance, thus saving IT resources. IT teams know they are providing the data services and performance applications that teams need. An excellent example of bringing enterprise-grade tools to K8s storage is its replication model, which allows automatic protection of storage object data and command line like other K8s services.
Dell continues to be the leader of the K8 community and has gained considerable credibility by integrating its storage with commonly used tools such as Grafana and Prometheus. Additionally, Dell works with all the most popular K8 platforms (VMware Tanzu, EKS, etc.), which is essential in today's multi-cloud world.
