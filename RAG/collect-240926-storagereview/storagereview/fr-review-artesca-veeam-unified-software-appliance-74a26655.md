# fr-review-artesca-veeam-unified-software-appliance-74a26655

<!-- source: https://www.storagereview.com/fr/review/artesca-veeam-unified-software-appliance -->

ARTESCA+ Veeam is the solution that brings backup software and storage together within a single platform. Concretely, it is a unified software appliance that runs Veeam Backup & Replication within Scality ARTESCA on a single server. Instead of configuring a Windows server for Veeam, a separate S3 target, and the interface between the two, customers can deploy a single system integrating the Veeam control plane and the S3 repository into one and the same architecture. According to Scality and Veeam, this single-host architecture eliminates the need for separate physical or virtual infrastructure for Veeam. It reduces complexity, time, and infrastructure costs of deployment by up to 30% compared to traditional multi-tier architectures.
Key points to remember
- Unified stack, reduced surface: Veeam and S3 operate within ARTESCA, internal traffic only, no external DNS, keys remain on the system.
- Installation in minutes: The wizard creates an account and a bucket, enables object lock and versioning, configures SOSAPI, transmits endpoints and credentials.
- Adapted capacity: From 20 to 440 TB usable on a standard x86 processor from HPE, Dell, Lenovo, or Supermicro.
- Resilience by default: CORE5 controls, IAM and optional MFA, Grafana visibility for day two.
How the unified appliance comes together
If you haven't been following object storage news recently, it's worth looking into the company behind ARTESCA. Scality has been developing large-scale file and object storage solutions since 2009, notably through its RING platform, which underpins vast on-premises object storage infrastructures at service providers and enterprises. The company has appeared for years in Gartner Magic Quadrant reports for file and object storage, was named a leader in the 2023 Magic Quadrant for distributed file systems and object storage, and then as a visionary in the 2024 Magic Quadrant for file and object storage platforms.
For a mid-sized IT team considering a relatively new product like ARTESCA, proven experience is essential to ensure it is an enterprise-grade storage solution offered by a reputable vendor, and not a side project of an unknown startup. ARTESCA is Scality's on-premises, cyber-resilient S3 object storage system, explicitly positioned as "storage designed for backup." Rather than tackling all possible use cases, ARTESCA focuses on backup and archive workloads, emphasizing immutability, ease of use, and the ability to scale from a few dozen terabytes to multi-petabyte environments without changing its management approach.
The current generation introduced Scality's CORE5 cyber-resilience framework, which layers API and identity plane protections all the way to the data path and cluster architecture, ensuring that backup data is protected against encryption, deletion, and insider abuse, and not just against accidental loss.
By design, ARTESCA+ Veeam isolates the S3 access path from the network. The S3 service is bound to internal interfaces; no external DNS entry is configured, and the access keys used by Veeam remain within the appliance. Communication between Veeam and the S3 buckets takes place over the appliance's internal infrastructure, reducing exposure to risk and simplifying auditing. This architecture also offers cost and performance benefits: the number of Ethernet ports required is reduced, and the backup window does not overload the network. If an external endpoint is necessary, it is an explicit and deliberate change that an administrator must enable and document, with the creation of new credentials for that purpose. In other words, the default configuration is exclusively internal, and external access is only allowed on request.
Veeam writes to ARTESCA buckets configured with versioning and S3 object lock, which makes backups immutable as soon as they are recorded. At the same time, ARTESCA ensures durability through erasure coding and data retention according to defined policies. Thus, your backup repository – the ultimate safeguard for your data – is part of a system designed to assume that a breach has occurred. This configuration reduces the attack surface and makes it extremely difficult for ransomware or insider threats to encrypt or delete your recovery copies.
Ease of use is another important aspect. ARTESCA was designed to be deployed and operated by the same teams that currently manage Veeam, without them needing to become S3 or Linux specialists. Upon first login, the appliance displays a partner application screen where you choose your backup software. By selecting Veeam, an integrated wizard opens and asks you a few targeted questions, instead of leaving you facing a blank S3 console. It creates the ARTESCA account that will manage Veeam resources, configures one or more buckets, enables versioning and object lock, sets logical capacity limits for reporting via Veeam's Smart Object Storage API (SOSAPI), then generates the endpoint and credentials needed for Veeam.
In practice, what usually required an hour of exchanges between backup and storage teams is now simplified. This guided process creates a functional and immutable repository in just a few minutes. Additionally, it provides a unified view of storage status and capacity, accessible via the ARTESCA user interface and the Veeam console.
From a business perspective, the combination of experience, security, and simplicity makes ARTESCA+ Veeam particularly appealing. Scality targets environments requiring between 20 and 440 TB of usable storage for its unified appliance. This solution is designed for agencies, edge sites, and mid-sized data centers that have outgrown the capabilities of traditional scale-up backup appliances, but do not want to build their own object storage platform.
For these teams, a software appliance integrating Veeam and S3 storage on a validated x86 server (optimized for Veeam's default block size of 1 MB) enables modernization of the backup infrastructure. This solution relies on documented reference architectures that demonstrate backup throughput of up to 5.5 TB/h and restore throughput of 4 TB/h on a single node, allowing teams to improve their backup capabilities without undertaking a full object storage project.
For this report, Scality provided us with a preconfigured ARTESCA+ Veeam system so that we could begin testing immediately. The hardware and initial configuration were specifically designed for our proof of concept and should not be considered a reference. In production, ARTESCA and ARTESCA+ Veeam are offered as software appliances that customers and partners can purchase and deploy on their validated x86 platforms, from vendors such as HPE, Dell, Lenovo, and Supermicro. They can also integrate these solutions into their own appliance or managed service offerings. This model preserves the flexibility needed to standardize on existing hardware or add value around the appliance, while leveraging the unified software stack we are evaluating here.
Guided tour of the user interface
Like many backup and storage platforms, the ARTESCA+ Veeam unified software appliance features a user-friendly web interface. Once installation is complete and after logging in, the "Overview" page appears, presenting a summary of the configuration. This step is typically performed by a partner, but the end customer can also do it. Key information, such as storage space used, active data services, and storage utilization percentage, is presented concisely and clearly.
The "Identity" page allows administrators to manage built-in users and groups and easily configure their permissions. Integration with LDAP directory servers is also possible, with preconfigured options for Microsoft Active Directory, Red Hat Directory, Tivoli Directory, and eDirectory. Multi-factor authentication can be enabled globally or for specific users.
The "Platform" page provides information about the server on which you chose to run the ARTESCA+ Veeam unified software appliance. The "Dashboard" tab displays service status, several activity graphs, and an "Advanced Metrics" button. Clicking this button opens the Grafana monitoring dashboard integrated into the appliance, which presents statistics on resource usage and server activity. This feature is particularly useful for organizations wanting to collect data on backup performance, network bandwidth usage, and reliability. It requires no additional installation or configuration during initial setup.
We have worked extensively with Grafana dashboards for storage solutions over the years. One of the most interesting aspects is that this service runs directly on the appliance. We are used to vendors offering Grafana dashboards that can be integrated into existing environments. ARTESCA goes further by providing an operational and deployed instance, ready to use for its customers. This is a considerable asset for monitoring services.
The "Nodes" tab allows you to configure additional ARTESCA+ nodes for redundancy, supporting 1, 3, or 6-node architectures. It is important to note that the ARTESCA+ Veeam solution is currently single-node; we are highlighting the broader ARTESCA features for reference. The "Volumes" tab allows administrators to create, modify, or delete volumes on connected nodes.
After installation, the volumes necessary for the operation of the ARTESCA+ Veeam unified software appliance are visible.
The "Storage Services" page allows you to manage the ARTESCA+ cluster and the individual data disks of the nodes. The "Expand Cluster" button allows you to add or remove nodes. When a node is selected, all its data disks are displayed. Faulty disks can be safely removed and replaced by clicking the "Unmount faulty disk" button. It is also possible to add disks by clicking the "Mount X new disks" button, where X represents the number of unused disks connected to the node. Like the "Dashboard" tab on the "Platform" page, the "Advanced Metrics" button opens Grafana and displays detailed statistics for the data disks of the selected node.
The next page is "Data Management." This view presents tabs titled "Accounts," "Data Explorer," "Workflows," "Locations," and "Data Services." Each tab controls functions essential to the operation of the ARTESCA+ Veeam unified software appliance.
If you use Microsoft's Azure cloud platform to store data, you are probably already familiar with the concept of storage "accounts." An account is a namespace containing one or more buckets, which serve as a repository for data objects, such as virtual machine backups. The contents of these buckets are visible by clicking on the "Data Explorer" tab and selecting the relevant bucket. This tab allows you to create, empty, delete, and modify the capacity of buckets. The "Workflows" tab allows you to configure automated replication, expiration, and transition actions (moving the contents of a bucket to another location, often used for archiving).
The "Locations" tab allows you to add additional internal or external repositories, including Amazon S3, Google Cloud Storage, Microsoft Azure Blob Storage, etc. Connected locations are listed on the page, and you can add new ones using the "Create Location" button on the right.
The "Data Services" tab displays the internal S3 endpoints used by the integrated Veeam instance. Unlike other ARTESCA deployment options that expose S3 endpoints via this tab, the ARTESCA+ Veeam unified software appliance does not support the creation of additional data services, thus ensuring a maximum level of security.
The last configuration element of the management interface is the "Alerts" page. This records current and past alerts, including those related to operating system updates, disks, services, nodes, and warnings about available space in volumes and the file system. You can also configure alert sending by email using the "Email Notification Configuration" button and the associated wizard.
Thanks to its intuitive user interface, the ARTESCA+ Veeam unified software can be easily configured to meet the backup and archiving needs of companies and organizations in various sectors, and is further enhanced by Veeam's ever-growing compatibility.
ARTESCA+ Veeam
The interface of the ARTESCA+ Veeam unified software appliance consists of the integrated Veeam instance. Running on KubeVirt, this Windows Server virtual machine, equipped with Veeam Backup & Replication, supports backing up virtual machines from various hypervisors, including Proxmox VE, Microsoft Hyper-V, VMware vSphere (ESXi/vCenter), Nutanix AHV, Oracle Linux Virtualization Manager, and many others. Faced with many customers migrating to virtualization solutions other than VMware-based ones, Veeam plans to soon extend support to other popular hypervisors, such as XCP-NG, HPE Morpheus VM Essentials, Citrix XenServer, and Red Hat OpenShift Virtualization. See the latest news regarding Veeam Data Platform v13.
The benefits of a unified software appliance
Veeam integration improves the performance, efficiency, and security of the Scality software appliance. Data transfer between Veeam and the S3 storage repository, provided by ARTESCA+, takes place internally via a virtualized network. This approach eliminates the need to duplicate external network traffic between hypervisors, data sources, Veeam, and the storage repository. It also helps protect the S3 bucket against attacks, thereby reducing the solution's attack surface.
To configure the S3 bucket used by the integrated Veeam virtual machine, log in to the ARTESCA+ web interface and go to the "Accounts" tab on the "Data Management" page. Then click the "Start Veeam VBR Wizard" button, which will display a wizard for configuring a storage account and bucket.
In our lab, the integrated Veeam wizard deployed a functional and immutable repository in a few minutes. It created the ARTESCA account, enabled versioning and object lock on the bucket, configured SOSAPI capacity reporting, and provided us with the endpoint, region, and keys needed for Veeam. Thanks to the internal communication between Veeam and the S3 service, no resources were exposed on the network and no DNS configuration was required, thus avoiding the usual back-and-forth between storage and backup teams. The process is simple for generalist IT professionals and, based on our experience, proved extremely reliable while retaining advanced control options.
Once the initial software configuration is complete, the Windows Server instance running Veeam Backup & Replication is accessible via RDP (Remote Desktop Protocol) or VNC. Veeam must then be connected to the ARTESCA+ S3 storage bucket using the "Backup Repositories" tab on the "Backup Infrastructure" page. Right-click on the tab, then select "Add Backup Repository" to add the previously created S3 bucket.
Select "Object Storage" in the list of backup repository types, then choose "S3 Compatible" on the next two pages. A wizard will then appear, prompting you to enter the connection information for the S3 bucket you created. The "Service Point" is found in the "Data Services" tab of the "Data Management" page in the ARTESCA+ web interface (in our case, it was "s3.artesca-plus-veeam.local"). Enter the region (available in the "Locations" tab) and credentials, select the previously created bucket and folder, then configure the "Mount Server" to be the Veeam server integrated into the ARTESCA+ Veeam unified software appliance. You can also set additional parameters, such as an object limit and whether to enable instant recovery with the vPower NFS service.
Veeam is now ready to connect to a data source or hypervisor to start backups.
ARTESCA+ Veeam and Proxmox VE
To test the ARTESCA+ Veeam unified software appliance, we connected the test unit to our Proxmox VE (PVE) server. Backing up virtual machines is done in three simple steps:
- Connecting the PVE cluster to Veeam
- Adding a worker virtual machine
- Creating a backup job
We will present the startup steps with Veeam, but a more detailed guide is available here: Veeam Plug-in for Proxmox VE 3 User Guide. To connect Veeam to PVE via the Backup & Replication console, go to the "Inventory" view, then select "Add Server" after right-clicking on the "Virtual Infrastructure" list item.
When the "Add Server" menu appears, follow the wizard's instructions to connect a Proxmox VE instance. You will be asked for the server's IP address or hostname and credentials, so make sure you have this information handy for your cluster.
After connecting the PVE, a worker virtual machine is needed to facilitate data transfers between the Proxmox VE server and Veeam. In the "Backup Infrastructure" view, right-click on "Backup Proxies," then select "Add Proxy" from the dropdown menu.
Add a worker process using the "Proxmox VE worker" wizard from the context menu, then select the desired host, CPU, memory, and network configuration. Name it (we used "artesca-worker") and complete the wizard.
Finally, we need to create a backup job to start backing up virtual machines on Proxmox VE. In the "Home" view of Veeam Backup & Replication, click on "Jobs," then "Backup." Right-click on "Backup," hover over "Backup" in the dropdown menu, and select "Virtual Machine."
A menu will then appear, allowing you to select the backup job settings. Be sure to include all virtual machines to be backed up using the "Add" button in the "Virtual Machines" step. Also select the ARTESCA+ S3 storage bucket as the backup repository. Once these steps are complete, the backup job will run according to your schedule.
Once you have configured Veeam to back up and store your hypervisors and data sources, the ARTESCA+ Veeam unified software appliance will run reliably in the background, protecting your organization's information and giving you peace of mind.

Conclusion
ARTESCA+ Veeam fully delivers on Scality's promises. In our lab, this unified software appliance eliminated backup and storage uncertainties by centralizing the S3 path, enabling versioning and object lock by default, and guiding installation through a simple and intuitive wizard usable by a generalist IT professional. The result: a functional and immutable repository in minutes, with minimal maintenance.
Security is focused on practicality rather than performance. Internal-only access points, no external DNS, credential isolation, Identity and Access Management (IAM), and optional multi-factor authentication (MFA) reduce exposure to risk while preserving day-to-day administrative simplicity. Grafana monitoring provides full visibility into services, nodes, and disks, making it easy to verify that backups are working properly and detect issues before they cause service disruptions.
From a business perspective, the added value lies in speed of implementation and reduced operational costs. Teams benefit from Veeam and an S3 target within a single infrastructure on standard x86, allowing them to maintain great flexibility in hardware choice and avoid vendor lock-in. Scality positions this unified appliance for usable capacity of approximately 20 to 440 TB, which corresponds to the needs of branch offices, edge sites, and SMBs that have outgrown the capabilities of a scale-up platform but do not want to deploy a separate object platform.
A few precautions should be taken into account. The unified appliance is a single node. For greater resilience or higher capacity, deploy ARTESCA in a multi-node cluster and keep Veeam as the control plane. External S3 exposure is possible, but it is an option to be enabled that must be documented and managed with separate credentials.
Overall, this is a mature approach, building on Scality's long experience and a team with decades of enterprise storage experience, combining sound defaults, strong immutability, and simple operations.
