# fr-review-artesca-veeam-unified-software-appliance-74a26655

ARTESCA+ Veeam is the solution that brings backup software and storage together within a single platform. Concretely, it is a unified software appliance that runs Veeam Backup & Replication within Scality ARTESCA on a single server. Instead of configuring a Windows server for Veeam, a separate S3 target, and the interface between the two, customers can deploy a single system integrating the Veeam control plane and the S3 repository into one and the same architecture. According to Scality and Veeam, this single-host architecture eliminates the need for separate physical or virtual infrastructure for Veeam. It reduces complexity, time, and infrastructure costs of deployment by up to 30% compared to traditional multi-tier architectures.
Key points to remember
- Unified stack, reduced surface: Veeam and S3 operate within ARTESCA, internal traffic only, no external DNS, keys remain on the system.
- Installation in minutes: The wizard creates an account and a bucket, enables object lock and versioning, configures SOSAPI, transmits endpoints and credentials.
- Adapted capacity: From 20 to 440 TB usable on a standard x86 processor from HPE, Dell, Lenovo, or Supermicro.
- Resilience by default: CORE5 controls, IAM and optional MFA, Grafana visibility for day two.
How the unified appliance comes together
If you haven't been following object storage news recently, it's worth looking into the company behind ARTESCA. Scality has been developing large-scale file and object storage solutions since 2009, notably through its RING platform, which underpins vast on-premises object storage infrastructures at service providers and enterprises. The company has appeared for years in Gartner Magic Quadrant reports for file and object storage, was named a leader in the 2023 Magic Quadrant for distributed file systems and object storage, and then as a visionary in the 2024 Magic Quadrant for file and object storage platforms.
For a mid-sized IT team considering a relatively new product like ARTESCA, proven experience is essential to ensure it is an enterprise-grade storage solution offered by a reputable vendor, and not a side project of an unknown startup. ARTESCA is Scality's on-premises, cyber-resilient S3 object storage system, explicitly positioned as "storage designed for backup." Rather than tackling all possible use cases, ARTESCA focuses on backup and archive workloads, emphasizing immutability, ease of use, and the ability to scale from a few dozen terabytes to multi-petabyte environments without changing its management approach.
The current generation introduced Scality's CORE5 cyber-resilience framework, which layers API and identity plane protections all the way to the data path and cluster architecture, ensuring that backup data is protected against encryption, deletion, and insider abuse, and not just against accidental loss.
By design, ARTESCA+ Veeam isolates the S3 access path from the network. The S3 service is bound to internal interfaces; no external DNS entry is configured, and the access keys used by Veeam remain within the appliance. Communication between Veeam and the S3 buckets takes place over the appliance's internal infrastructure, reducing exposure to risk and simplifying auditing. This architecture also offers cost and performance benefits: the number of Ethernet ports required is reduced, and the backup window does not overload the network. If an external endpoint is necessary, it is an explicit and deliberate change that an administrator must enable and document, with the creation of new credentials for that purpose. In other words, the default configuration is exclusively internal, and external access is only allowed on request.
Veeam writes to ARTESCA buckets configured with versioning and S3 object lock, which makes backups immutable as soon as they are recorded. At the same time, ARTESCA ensures durability through erasure coding and data retention according to defined policies. Thus, your backup repository – the ultimate safeguard for your data – is part of a system designed to assume that a breach has occurred. This configuration reduces the attack surface and makes it extremely difficult for ransomware or insider threats to encrypt or delete your recovery copies.
Ease of use is another important aspect. ARTESCA was designed to be deployed and operated by the same teams that currently manage Veeam, without them needing to become S3 or Linux specialists. Upon first login, the appliance displays a partner application screen where you choose your backup software. By selecting Veeam, an integrated wizard opens and asks you a few targeted questions, instead of leaving you facing a blank S3 console. It creates the ARTESCA account that will manage Veeam resources, configures one or more buckets, enables versioning and object lock, sets logical capacity limits for reporting via Veeam's Smart Object Storage API (SOSAPI), then generates the endpoint and credentials needed for Veeam.
In practice, what usually required an hour of exchanges between backup and storage teams is now simplified. This guided process creates a functional and immutable repository in just a few minutes. Additionally, it provides a unified view of storage status and capacity, accessible via the ARTESCA user interface and the Veeam console.
From a business perspective, the combination of experience, security, and simplicity makes ARTESCA+ Veeam particularly appealing. Scality targets environments requiring between 20 and 440 TB of usable storage for its unified appliance. This solution is designed for agencies, edge sites, and mid-sized data centers that have outgrown the capabilities of traditional scale-up backup appliances, but do not want to build their own object storage platform.
For these teams, a software appliance integrating Veeam and S3 storage on a validated x86 server (optimized for Veeam's default block size of 1 MB) enables modernization of the backup infrastructure. This solution relies on documented reference architectures that demonstrate backup throughput of up to 5.5 TB/h and restore throughput of 4 TB/h on a single node, allowing teams to improve their backup capabilities without undertaking a full object storage project.
For this report, Scality provided us with a preconfigured ARTESCA+ Veeam system so that we could begin testing immediately. The hardware and initial configuration were specifically designed for our proof of concept and should not be considered a reference. In production, ARTESCA and ARTESCA+ Veeam are offered as software appliances that customers and partners can purchase and deploy on their validated x86 platforms, from vendors such as HPE, Dell, Lenovo, and Supermicro. They can also integrate these solutions into their own appliance or managed service offerings. This model preserves the flexibility needed to standardize on existing hardware or add value around the appliance, while leveraging the unified software stack we are evaluating here.
Guided tour of the user interface
Like many backup and storage platforms, the ARTESCA+ Veeam unified software appliance features a user-friendly web interface. Once installation is complete and after logging in, the "Overview" page appears, presenting a summary of the configuration. This step is typically performed by a partner, but the end customer can also do it. Key information, such as storage space used, active data services, and storage utilization percentage, is presented concisely and clearly.
The "Identity" page allows administrators to manage built-in users and groups and easily configure their permissions. Integration with LDAP directory servers is also possible, with preconfigured options for Microsoft Active Directory, Red Hat Directory, Tivoli Directory, and eDirectory. Multi-factor authentication can be enabled globally or for specific users.
