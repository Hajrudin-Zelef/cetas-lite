# fortigate-3-technical-tip-collect-device-parameters-of-all-the-connected-devices-fa4fcb31

Technical Tip: Collect device parameters of all the connected devices in the network from FortiGate
| Description | This article describes how to retrieve useful device parameters like MAC address, IP address, vendor details, OS details, firmware version, etc, of all the connected devices in the network in real-time from the FortiGate. | 
| Scope | FortiGate. | 
| Solution | Retrieving information about devices connected at the present moment in the network would be useful for analysis while troubleshooting, or for monitoring in general. FortiGate provides a simple user interface to collect such information of devices connected in the network in real-time, both from the GUI as well as from CLI (& API). If FortiGate is used to manage FortiSwitches using FortiLink, then the FortiGate inventory list would have more information regarding the connected devices in the managed switch topology. | <e8:1d:ba:73:cb:14> | MAC address of the device. |

| seen | The device was last seen. | 
| <port/vlan> | The port or VLAN on which this device was detected. |

| software version | software/firmware version detected on the device. | 
| host | The hostname of the device. |
