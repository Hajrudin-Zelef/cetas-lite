# Microsoft launches Intelligent Terminal, an open source terminal that lets you choose your AI

## What to remember AI-generated summary

1. Microsoft presented Intelligent Terminal 0.1, an open source terminal under MIT license that integrates AI assistants into a command window via a side panel called agent pane, capable of detecting errors and proposing corrections.
2. The tool accepts any agent compatible with the Agent Client Protocol (ACP), allowing the user to choose between GitHub Copilot CLI, Claude Code, Codex or other AI assistants instead of being limited to the Microsoft solution.
3. Intelligent Terminal only works on Windows for now despite its open code, and installs via the Microsoft Store or winget without replacing the existing Windows Terminal, while remaining in an experimental state.

Microsoft presented on June 2, during its Build 2026 developer conference, an experimental version of its terminal called Intelligent Terminal 0.1, an open source software published under MIT license that directly integrates AI assistants into the window where you type commands.

To put it in context if you're really very noob, the terminal is that text interface that developers and system administrators use daily to launch commands, compile code or control a remote server. Microsoft has already offered Windows Terminal for years, and Intelligent Terminal is a distinct variant, not a replacement.

The central element is the agent pane, a panel anchored to the side of the window that acts as a copilot. It continuously reads what is displayed in your terminal, and when a command fails, it detects the error and offers you an explanation or a fix.

You can choose to receive a simple notification in the status bar, or let the assistant directly apply its corrections according to the configuration you have defined.

There is also a trick integrated into the command palette: type a question mark followed by your request, and the tool launches a background task in a dedicated tab, without blocking the current session. Handy when you want to delegate a long operation without interrupting your work.

On the assistants side, Microsoft made an open choice. By default, it's GitHub Copilot CLI, the in-house assistant that works on the command line. But Intelligent Terminal accepts any agent compatible with the Agent Client Protocol (ACP), a standard that allows different AI assistants to plug into the same tool.

You can therefore use Claude Code, the coding assistant from Anthropic, OpenAI's competitor, or Codex, OpenAI's in-house equivalent, instead of Microsoft's solution. That's rare enough for the Windows publisher to be worth noting.

The software installs from the Microsoft Store or via the command winget install Microsoft.IntelligentTerminal, and it sits alongside Windows Terminal without replacing it. Microsoft specifies that if you don't want AI in your usual terminal, nothing changes for you.

There is still one detail that sticks, and it's Phoronix, the site specialized in Linux news, that points it out: despite its open code published under MIT license, Intelligent Terminal only runs on Windows for now.

We're also talking about a version 0.1 stamped experimental, which announces bugs and changes to come before a possible stable version.

In short, an open source terminal that lets the user choose their AI instead of imposing its own is a rather well-thought-out gesture on Microsoft's part.
