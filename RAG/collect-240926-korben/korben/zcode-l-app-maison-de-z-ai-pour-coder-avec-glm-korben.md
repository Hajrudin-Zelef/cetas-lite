# ZCode - z.ai's in-house app for coding with GLM

## What to remember AI-generated summary

1. ZCode is z.ai's desktop application for coding with AI agents, available on Mac, Windows, and Linux (beta), designed for long tasks where you set Goals and the agent plans, executes, and verifies its work step by step.
2. The app includes a file manager, terminal, Git panel, live browser preview, supports the MCP protocol, lets you launch multiple agents in parallel, and offers remote control via WeChat or Feishu, all starting at 18 dollars per month on the GLM Coding Plan.
3. The application is recent and suffers from crashes on Apple Silicon, including losses of unsaved work and persistent black windows after relaunching, which is a problem for managing long work sessions.

Yesterday I was telling you about GLM 5.2 , the open source model that I ended up adopting (in part) for working. Well, the z.ai team (the Chinese lab formerly known as Zhipu AI) keeps up the good work and is now pushing ZCode , their own application for coding with AI agents.

It's a desktop app that runs on Mac, Windows, and Linux (in beta for the latter), and it's designed for tasks that last. The idea is Goals that you set, and the agent plans, executes, and verifies its work on its own step by step, while you follow the progress.

So you have a real environment with a file manager, terminal, Git panel, and live browser preview, it supports the MCP protocol, it can launch multiple agents in parallel, and you can even control your tasks remotely from WeChat or Feishu. And the whole thing runs on the same GLM Coding Plan as the rest of their ecosystem, starting at 18 dollars per month.

If you follow me, you already know that GLM 5.2 plugs directly into Claude Code, because z.ai's API is Anthropic-compatible. I had also given you the little launcher for that no later than yesterday. But this ZCode is above all a good showcase for z.ai, to keep us in their app rather than using the competition. Either way, nothing mandatory, you should see this ZCode as one more option for coding with the help of AI.

The app is very recent and digging through their feedback repo , I see that the app still suffers from quite painful crashes on Apple Silicon, including errors that make you lose unsaved work and a window that sometimes stays black even after relaunching the app. That's a bit discouraging for something supposed to handle long work sessions... But I think it will quickly stabilize, given how much good work the Z.ai devs are doing.

If you're already subscribed to the GLM Coding Plan, it won't cost you anything extra to try it just to see if the Goals match your way of working. And otherwise, for others, the API + your usual tool will do the job just as well.
