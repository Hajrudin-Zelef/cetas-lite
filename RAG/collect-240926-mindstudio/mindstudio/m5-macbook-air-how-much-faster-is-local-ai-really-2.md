# m5-macbook-air-how-much-faster-is-local-ai-really

Based on memory bandwidth alone, the M5 is about 26 percent faster than the M4. Real-world token generation gains will track close to that figure since generation speed is bandwidth-bound.

### Does the MacBook Air throttle when running heavy local AI workloads?

Yes. Sustained, all-core workloads cause measurable slowdowns on every Air generation tested, and the M5 showed the largest drop, around 6 percent, from its first workload iteration to its last.

## Remy doesn't build the plumbing. It inherits it.

Remy ships with all of it from MindStudio — so every cycle goes into the app you actually want.

### Should I buy 16 GB or more memory for local AI on the M5?

Since the M4 and M5 both start at 16 GB minimum, anyone planning to run larger local models should consider upgrading further, since memory capacity determines what size model can be loaded at all, separate from how fast that memory moves data.
