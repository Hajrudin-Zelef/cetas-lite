## How to read this file

- Every factual bullet and every table row carries exactly one provenance tag: `[official]`, `[vendor-reported]`, `[independent]`, `[secondary]`, or `[unverified]`.
- `[official]` = the language/runtime vendor's own documentation or release page. `[vendor-reported]` = a vendor's own claim about itself (marketing, blog) — true as stated by the vendor, not independently verified. `[independent]` = third-party benchmark, audit, or measurement with stated methodology. `[secondary]` = press/blog/GitHub mirrors restating vendor or survey data without full methodology. `[unverified]` = could not be confirmed from an authoritative source within this research session.
- Search snippets fetched on 2026-09-22 are treated as `[secondary]` unless they quote an official release page verbatim.
- ⚠️ Do not compare rankings across TIOBE, Stack Overflow, and GitHub Octoverse: different populations, different methods, different questions (see §14) [secondary].
