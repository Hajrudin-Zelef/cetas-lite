# Print the public key â you will need it for the client config

A road warrior VPN lets a single device â your laptop or phone â connect back to your home or office network from anywhere. WireGuard on RouterOS 7 makes this trivial to set up and lightning fast to connect.

## Prerequisites

- RouterOS 7.1 or newer
- A public IP or DDNS hostname on the router
- WireGuard app installed on your client device (iOS, Android, Windows, Linux)

## Step 1: Create the WireGuard Interface

Create the server-side WireGuard interface. RouterOS generates the keypair automatically.

```
/interface/wireguard
add listen-port=51820 mtu=1420 name=wg-rw
# Print the public key â you will need it for the client config
/interface/wireguard/print
```
## Step 2: Assign a Tunnel Address

Give the router an address on the WireGuard subnet. Clients will receive addresses in this range.

```
/ip/address
add address=10.99.0.1/24 interface=wg-rw comment="WireGuard RW pool"
```
## Step 3: Generate Client Keys

On a Linux or macOS machine generate a keypair for each client. On Windows use the WireGuard app to generate keys automatically.

```
wg genkey | tee client_private.key | wg pubkey > client_public.key
cat client_private.key
cat client_public.key
```
## Step 4: Add the Peer on the Router

```
/interface/wireguard/peers
add allowed-address=10.99.0.2/32 \
    interface=wg-rw \
    public-key="PASTE_CLIENT_PUBLIC_KEY_HERE" \
    comment="Laptop"
```
Each client device needs its own peer entry with a unique allowed-address. Never reuse a /32 address between peers.

## Step 5: Firewall Rules

```
# Allow WireGuard handshakes inbound
/ip/firewall/filter
add chain=input action=accept protocol=udp dst-port=51820 comment="WireGuard in" place-before=0
# Allow forwarding from tunnel to LAN
add chain=forward action=accept in-interface=wg-rw comment="WireGuard fwd" place-before=0
```
## Step 6: Client Configuration

Create this config file on the client device (or scan the QR code generated by the WireGuard app):

```
[Interface]
PrivateKey = PASTE_CLIENT_PRIVATE_KEY
Address    = 10.99.0.2/24
DNS        = 10.99.0.1
[Peer]
PublicKey  = PASTE_ROUTER_PUBLIC_KEY
Endpoint   = your.ddns.com:51820
AllowedIPs = 0.0.0.0/0
PersistentKeepalive = 25
```
## Verification

Check the handshake on the router. A fresh timestamp means the tunnel is active.

```
/interface/wireguard/peers/print detail
# Look for: last-handshake=Xs ago
```
1. Ping the router tunnel address from the client: ping 10.99.0.1
2. Ping a LAN host: ping 192.168.1.1
3. Check the peer rx/tx counters increment
