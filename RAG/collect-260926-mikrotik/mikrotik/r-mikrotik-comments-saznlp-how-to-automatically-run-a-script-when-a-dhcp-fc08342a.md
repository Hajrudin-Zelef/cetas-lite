# r-mikrotik-comments-saznlp-how-to-automatically-run-a-script-when-a-dhcp-fc08342a

How to automatically run a script when a DHCP lease is issued/renewed? 
        
        
        
    
    
    I am using this script from the wiki to create DNS records for my local hosts: https://wiki.mikrotik.com/wiki/Setting_static_DNS_record_for_each_DHCP_lease
Currently I have to connect to my router and run the script manually every time I add a new host to my network. Is it somehow possible to automate this so that the script is executed when new hosts appear on the network?
A time schedule is not a good solution because normally when I add a new host I want to immediately SSH into it and set it up, and it turns out to be quicker to connect to the router and run the auto-DNS script, than to wait minutes for it to be executed automatically on schedule. I am looking for some type of an event-based solution, if such solution exists.
Section des commentaires
You can trigger a script when a new lease is issued right from the DHCP server config.
/ip dhcp-server lease-script={Script code here}
There is a little more info on the wiki https://wiki.mikrotik.com/wiki/Manual:IP/DHCP_Server#General

Sorry I didn't include proper syntax. Since you are editing a existing dhcp-server You would want to use the
setcommand along with the index generated by theprintcommand.
So first show all existing dhcp-servers with
/ip dhcp-server print. This will output all dhcp servers along with a "item number" index. If you only have have one dhcp server it will have a "item number" of 0 so to change the command it will be/ip dhcp-server set 0 lease-script={your sctipt}
More info on the command line item number system can be found here. https://wiki.mikrotik.com/wiki/Manual:Console#Item_Numbers
You need to specify the DHCP server you want to edit/view, as you may have more than one.
If you only have one, then this will be 0.
See https://wiki.mikrotik.com/wiki/Manual:IP/DHCP_Client#Lease_script_example
and https://forum.mikrotik.com/viewtopic.php?t=161511
