## Introduction to GitHub and its ecosystem

Many people know GitHub as a code hosting platform, but GitHub is much more than that. It is a central cog in the software development cycle, because it supports version control, which is key to collaborating on projects. Here is an overview of the main GitHub products, designed to cover most needs.

- GitHub Free: ideal for individual developers or small teams, with unlimited public and private repositories and basic collaboration tools.
- GitHub Pro: adds advanced features such as repository insights and additional storage, perfect for experienced developers seeking expanded capabilities.
- GitHub Team: this offering strengthens team collaboration with, for example, multiple reviewers on pull requests and advanced project management tools.
- GitHub Enterprise: intended for large organizations, with advanced security and compliance features, as well as flexible deployment options such as GitHub Enterprise Cloud and GitHub Enterprise Server.

GitHub also offers complementary tools such as GitHub Desktop, GitHub Mobile, and GitHub Actions, designed for demanding users who want to maximize their productivity.

## Overview of GitHub account types and plans

GitHub offers different account types, with feature sets tailored to various levels of collaboration and project management. To help you choose the GitHub account type that suits you, use the decision tree below. It will guide you through a few questions to determine whether a Personal, Organization, or Enterprise account best meets your needs.

*How to choose the right GitHub account type. Image: Napkin.AI*

### Personal accounts

Personal accounts are perfect for individual users, such as freelancers or students, who are looking for a simple way to manage their projects. They provide access to an unlimited number of public and private repositories. Basic collaboration tools allow for light team interactions, and GitHub Pages offers the ability to host simple websites directly from your repositories. Personal accounts come in two plans, GitHub Free or GitHub Pro:

#### GitHub Free

The GitHub Free plan is available for personal and organizational accounts. It provides the essentials, including unlimited public and private repositories, GitHub community support, and basic capabilities for GitHub Actions. This plan is ideal for individuals and small teams getting started with version control and collaborative code. It allows you to host projects, collaborate, and automate workflows with GitHub Actions, but with limited resources.

#### GitHub Pro

GitHub Pro is aimed at individual developers who need advanced features to manage their projects. In addition to what GitHub Free offers, Pro users benefit from advanced repository insights, additional GitHub Actions minutes, and more storage for GitHub Codespaces. This plan is suitable for developers who want to go further in analyzing their projects and who need increased resources for their CI/CD pipelines and cloud development environments.

### Organization and Enterprise accounts

Two other account types offer enhanced features for managing teams and projects: organization accounts and enterprise accounts. Organization accounts provide role-based access controls, multiple reviewers on pull requests, and centralized billing. Enterprise accounts target large companies, with advanced security measures such as single sign-on (SSO), audit logs, and flexible deployment options. These accounts require more resources and administration, with enterprise accounts offering the highest level of control and security for large-scale operations.

#### GitHub Team

The GitHub Team plan is ideal for organizations that need enhanced collaboration features. It builds on GitHub Free by adding tools that optimize team workflows, such as multiple reviewers for pull requests, team reminders, and repository insights graphs. This plan is suitable for companies that need to coordinate the work of multiple developers while maintaining an overall view of progress.

#### GitHub Enterprise

GitHub Enterprise is the most advanced offering, with additional security, compliance, and deployment controls. It is aimed at large organizations that require a high level of control over their development processes. Enterprise customers can choose GitHub Enterprise Cloud or GitHub Enterprise Server, depending on their deployment needs. This offering includes advanced features such as single sign-on (SSO), audit logs, and dedicated support, making it ideal for organizations subject to strict regulatory requirements.

Regarding GitHub Enterprise, managed user accounts should also be mentioned. If you are part of an enterprise account, you are probably using a managed account, which means you must sign in to access your organization's repositories. Companies want to retain control over user activity. You can still create private repositories, but your ability to publish publicly or contribute outside the company network will be restricted, which makes sense given privacy concerns.

## GitHub's complementary tools

In addition to its flagship products, GitHub offers several auxiliary tools that support developers. They make repository management, collaboration, and project tracking easier, whether you are traveling or working remotely.

*GitHub Desktop and GitHub Mobile. Image: Napkin.Ai*

### GitHub Desktop

GitHub Desktop is a user-friendly application that simplifies local management of your repositories. Its graphical interface allows you to manage Git and GitHub workflows without using the command line. With GitHub Desktop, you can clone repositories, create branches, commit changes, and push updates in just a few clicks. This tool is particularly useful for those who prefer a visual approach to code management, as it avoids complex Git commands while offering solid functional coverage.

### GitHub Mobile

GitHub Mobile lets you stay connected to your projects wherever you are. You can perform most key actions directly from your phone, such as reviewing code or merging pull requests. That said, GitHub Mobile does not replace your main work environment: it is more of a welcome complement. It is especially valuable for staying on top of important notifications and quickly resolving issues, since your phone goes everywhere with you. ## Billing, licenses, and notifications on GitHub

GitHub offers subscription and usage-based billing models, suited to a variety of needs and project sizes.

### Billing structure

GitHub billing comes in two main modes: subscription and usage-based.

- Subscription billing: this model covers the GitHub Free, Pro, Team, and Enterprise plans, each with a fixed monthly or annual cost. Free is suitable for basic needs, while Pro adds features at a higher price. Team offers collaborative tools at a per-user price, and Enterprise is aimed at large organizations with advanced security and compliance features. Enterprise licenses are generally based on the number of users, with a recently introduced consumption-based model that adjusts to usage.
- Usage-based billing: this model applies to services such as GitHub Actions, GitHub Packages, and GitHub Codespaces. Although free quotas are included, usage beyond them incurs additional costs. For example, GitHub Actions lets you automate workflows with free minutes, but excess usage is billed. Likewise, GitHub Packages and Codespaces charge for storage and compute time beyond the quotas.

### Controlling costs

To better manage spending, GitHub allows organizations to set spending caps for Actions, Packages, and Codespaces. These limits prevent exceeding a given budget and avoid surprises. GitHub also provides detailed usage reports and a billing dashboard, which helps track spending closely and stay within the planned budget.

### Managing notifications and subscriptions

GitHub notifications are extremely useful. They inform you of any important changes made to your repository. Since staying up to date in a collaborative project is essential, GitHub offers several options for managing them.

You can receive notifications through the web interface, by email, or via GitHub Mobile, all synchronized. In addition, you can customize them to see only what matters to you. If, for example, you want to follow pull requests but not the activity in discussions, keep notifications for pull requests and mute conversations.

You can also set up email filters or choose to be alerted for specific events such as workflow runs or security alerts. Notifications are so convenient on GitHub that many people use them as a triage tool: you can mark certain notifications as "Done" or save others to handle later.

## Frequently asked questions about GitHub

### Is GitHub free?

**GitHub offers free and paid plans.**

### Who should use GitHub Team?

**GitHub Team is designed for organizations that need advanced collaboration features, such as multiple reviewers and advanced project management tools.**

### What GitHub certifications does it offer?

**There are several GitHub certifications, but the most fundamental is GitHub Foundations. It is ideal for beginners who want to acquire the basics of Git and GitHub.**

### What is GitHub Actions?

**GitHub Actions automates workflows such as building, testing, and deploying code.**

### Can managed users access personal repositories?

**No, managed users do not have access to personal repositories. They can only access the repositories and resources of the enterprise organization.**
