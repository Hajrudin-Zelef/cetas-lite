# introduction-aux-produits-github-le-guide-complet

GitHub Desktop is a user-friendly application that simplifies local management of your repositories. Its graphical interface allows you to manage Git and GitHub workflows without using the command line. With GitHub Desktop, you can clone repositories, create branches, commit changes, and push updates in just a few clicks. This tool is particularly useful for those who prefer a visual approach to code management, as it avoids complex Git commands while offering solid functional coverage.

### GitHub Mobile

GitHub Mobile lets you stay connected to your projects wherever you are. You can perform most key actions directly from your phone, such as reviewing code or merging pull requests. That said, GitHub Mobile does not replace your main work environment: it is more of a welcome complement. It is especially valuable for staying on top of important notifications and quickly resolving issues, since your phone goes everywhere with you. ## Billing, licenses, and notifications on GitHub

GitHub offers subscription and usage-based billing models, suited to a variety of needs and project sizes.

### Billing structure

GitHub billing comes in two main modes: subscription and usage-based.

- Subscription billing: this model covers the GitHub Free, Pro, Team, and Enterprise plans, each with a fixed monthly or annual cost. Free is suitable for basic needs, while Pro adds features at a higher price. Team offers collaborative tools at a per-user price, and Enterprise is aimed at large organizations with advanced security and compliance features. Enterprise licenses are generally based on the number of users, with a recently introduced consumption-based model that adjusts to usage.
- Usage-based billing: this model applies to services such as GitHub Actions, GitHub Packages, and GitHub Codespaces. Although free quotas are included, usage beyond them incurs additional costs. For example, GitHub Actions lets you automate workflows with free minutes, but excess usage is billed. Likewise, GitHub Packages and Codespaces charge for storage and compute time beyond the quotas.

### Controlling costs

To better manage spending, GitHub allows organizations to set spending caps for Actions, Packages, and Codespaces. These limits prevent exceeding a given budget and avoid surprises. GitHub also provides detailed usage reports and a billing dashboard, which helps track spending closely and stay within the planned budget.

### Managing notifications and subscriptions

GitHub notifications are extremely useful. They inform you of any important changes made to your repository. Since staying up to date in a collaborative project is essential, GitHub offers several options for managing them.

You can receive notifications through the web interface, by email, or via GitHub Mobile, all synchronized. In addition, you can customize them to see only what matters to you. If, for example, you want to follow pull requests but not the activity in discussions, keep notifications for pull requests and mute conversations.

You can also set up email filters or choose to be alerted for specific events such as workflow runs or security alerts. Notifications are so convenient on GitHub that many people use them as a triage tool: you can mark certain notifications as "Done" or save others to handle later.

## Frequently asked questions about GitHub

### Is GitHub free?

**GitHub offers free and paid plans.**

### Who should use GitHub Team?

**GitHub Team is designed for organizations that need advanced collaboration features, such as multiple reviewers and advanced project management tools.**

### What GitHub certifications does it offer?

**There are several GitHub certifications, but the most fundamental is GitHub Foundations. It is ideal for beginners who want to acquire the basics of Git and GitHub.**

### What is GitHub Actions?

**GitHub Actions automates workflows such as building, testing, and deploying code.**

### Can managed users access personal repositories?

**No, managed users do not have access to personal repositories. They can only access the repositories and resources of the enterprise organization.**
