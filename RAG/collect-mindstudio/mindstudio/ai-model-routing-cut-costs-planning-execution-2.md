# AI Model Routing: How to Cut Costs 60% by Matching Tasks to the Right Model

- Pricing tiers (mid-2025): Frontier $3–$15/M input; Mid-tier $0.10–$0.60/M; Local/Open ~$0 (self-hosted).
- Example model classes: frontier GPT-4o/Claude 3.5 Sonnet/Gemini 1.5 Pro; mid-tier Claude 3 Haiku/GPT-4o mini/Gemini 1.5 Flash; open Llama 3.1/Mistral/Phi-3.
- Scenario 1: 50K docs/month; without routing ~$900, with routing ~$350 (savings ~61%).
- Scenario 2: 10K support interactions/month; without routing ~$600, with routing ~$200 (savings ~67%).
- Batch API: ~50% cost reduction for non-time-sensitive processing.
- Routing signals: ambiguity of input, judgment required, output sensitivity, volume.
