# hc-en-us-articles-27130425853079-configuring-touch-pass-in-unifi-access-44e73df1

- If you have multiple consoles, all Touch Passes will be restored to a selected console. During the dissolve process, the admin can choose which console to restore the Touch Passes to. All Touch Passes are then stored on a single console.
