# hc-en-us-articles-37877072963607-upgrading-to-early-access-in-unifi-4b73c556

Upgrading to Early Access in UniFi
UniFi Early Access provides early access to upcoming features and improvements across UniFi software, firmware, and Site Manager. Early Access must be enabled at the account level first, after which eligible site owners can enable it for Site Manager and select Early Access release channels for software and firmware.
Enroll in Early Access
Early Access must be enabled on your UI account before it can be used anywhere in UniFi.
- Sign into account.ui.com.
- Click Account Information.
- Enable Early Access under Preferences.
Enable Early Access in Site Manager
- Navigate to Site Manager.
- Sign in with your UI Account.
- Click the profile icon in the upper-right corner.
- Enable Early Access.
Enable Early Access for UniFi Software & Firmware
After Early Access is enabled at the account level, site owners with the appropriate permissions can select the Early Access release channel for UniFi OS and applications.
- Select a site in Site Manager.
- Navigate to Settings > Updates.
- Select UniFi OS and/or Application(s).
- Set the release channel to Early Access.
- Update the UniFi Console and/or UniFi applications as needed.
