# questions-android-tablet-will-not-connect-to-unifi-73fa91bb-7bfd-413e-802e-ef53a-1ccc7422

@UI-Team
I recently purchased a Lenovo TAB4 8 and have been trying to connect it to our Unifi AP AC LITE for last 5 days. I have tried just about everything I can think of. It appears that the TAB4 8 only has 2.4Ghz capabilities but I am still awaiting Lenovo's answer on that. Regardless of Lenovo's response, even if I set up a new SSID and password in the Unifi controller which only transmits 2.4Ghz (ie. I turned off the 5Ghz option) my TAB4 8 will only occassionally see the SSID and if it does it only connects for a few seconds. I have also tried this with an open connection (without a password). I have also tried setting the radio to maximum power and even with the TAB4 8 right next to the transmitter I only get a very weak signal showing on the TAB4 8 which almost immediatey disappears when I connect.
The interesting aspect of this is that the TAB4 8 connects perfectly to another non Unifi access point which is transmitting 2.4Ghz.
To me this means there is a problem with the Unifi product's ability to transmit an easily recognised 2.4Ghz radio signal. It has the latest firmware and works perfectly with any other device although I must add that all other devices connect to it on 5Ghz.
Can anyone offer any advice or support with this matter. BTW the Tablet has the latest system update installed and is using Android version 7.1.1
