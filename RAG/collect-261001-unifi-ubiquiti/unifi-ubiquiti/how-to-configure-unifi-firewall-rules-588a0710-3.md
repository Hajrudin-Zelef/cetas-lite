# how-to-configure-unifi-firewall-rules-588a0710

These UniFi firewall best practices all assume the same build order: zones first, so the defaults are right, then the device-level exceptions. The other way around leaves you with a pile of policies and no idea which of them are load-bearing. Security changes and nothing here is a guarantee, so treat a policy set as something you re-read after firmware updates and whenever a new device shows up.
