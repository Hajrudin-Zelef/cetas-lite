Application Filtering in UniFi
UniFi’s Next-Gen Firewall (NGFW) is equipped with powerful application control, allowing you to quickly block or allow specific applications or entire categories of applications.
For a full overview of UniFi's Network and Cyber Security capabilities, see here.
For a full overview of UniFi’s Traffic and Policy Management capabilities, see here.
Filtering Applications
UniFi Network offers two methods for filtering applications, based on the level of control and granularity you need:
- Simple App Blocking: Quickly block specific applications or entire categories for selected networks or client devices.
- Zone-Based Firewall: Offers the same app filtering capabilities, but with deeper traffic control so you can apply rules by firewall zone, and match on advanced criteria such as protocol, port, or even connection state.
For more granular content-based filtering in UniFi, see here.
Simple Application Filtering
To set up basic application filtering:
- Navigate to Settings > CyberSecure > Protection > Simple App Blocking.
- Select the devices or networks where you want to apply filtering.
- Select from Specific App(s) or App Categories.
- (Optional) Configure a Schedule for when the rule should apply.
