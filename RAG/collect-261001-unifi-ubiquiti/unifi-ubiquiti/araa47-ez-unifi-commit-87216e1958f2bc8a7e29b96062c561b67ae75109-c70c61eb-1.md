|  | 7 | +# ez-unifi | 
|  | 8 | + | 
|  | 9 | +Agent-friendly UniFi Network tools powered by the `aiounifi` library. Supports UDM Pro/SE, Dream Machine, Cloud Key Gen2+, and self-hosted controllers. | 
|  | 10 | + | 
|  | 11 | +**Run all commands with:** `uv run scripts/unifi.py <command> [args]` | 
|  | 12 | + | 
|  | 13 | +## Setup | 
|  | 14 | + | 
|  | 15 | +**Step 1: Ask user to create a dedicated local admin account** | 
|  | 16 | + | 
|  | 17 | +> To manage your UniFi network, I need API access. Please create a dedicated local admin account: | 
|  | 18 | +> | 
|  | 19 | +> 1. Open your UniFi controller (e.g., https://192.168.1.1) | 
|  | 20 | +> 2. Go to **Settings → System → Admins & Users** | 
|  | 21 | +> 3. Click **Add Admin** | 
|  | 22 | +> 4. Enter a username (e.g., `agent-api`) | 
|  | 23 | +> 5. Enter an email and password | 
|  | 24 | +> 6. **Important: Disable "Remote Access"** - local-only avoids MFA issues | 
|  | 25 | +> 7. Set Role to **Super Admin** or **Site Admin** | 
|  | 26 | +> 8. Click **Add** | 
|  | 27 | +> | 
|  | 28 | +> Then provide: | 
|  | 29 | +> - Controller IP (e.g., `192.168.1.1`) | 
|  | 30 | +> - Username | 
|  | 31 | +> - Password | 
|  | 32 | +> - Is it a UDM Pro/SE/Dream Machine? (yes/no) | 
|  | 33 | + | 
|  | 34 | +**Step 2: Save credentials to `.env`** | 
|  | 35 | + | 
|  | 36 | +```bash | 
|  | 37 | +UNIFI_HOST=https://192.168.1.1 | 
|  | 38 | +UNIFI_USERNAME=agent-api | 
|  | 39 | +UNIFI_PASSWORD=the_password | 
|  | 40 | +UNIFI_SITE=default | 
|  | 41 | +UNIFI_IS_UDM=true | 
|  | 42 | +``` | 
|  | 43 | + | 
|  | 44 | +Set `UNIFI_IS_UDM=false` for Cloud Key Gen1 or self-hosted controllers. |
