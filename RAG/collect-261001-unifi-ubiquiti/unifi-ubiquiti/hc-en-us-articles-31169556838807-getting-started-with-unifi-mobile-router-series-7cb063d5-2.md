# hc-en-us-articles-31169556838807-getting-started-with-unifi-mobile-router-series-7cb063d5

      - Target IP Address: UMR LAN IP (e.g., 192.168.105.1).
- Important: 
- Access the UMR remotely using: https://[PUBLIC_IP]:[CUSTOM_PORT]
Example: https://101.13.5.97:8787
- If remote access fails:
  - Ensure your ISP is not blocking external connections.
  - Double-check port forwarding rules in your UMR settings.
  - If remote access fails, try using a different external port.
