# home-network-unifi-design-center-95063108

The equipment list overview will show you all the devices and their list price, that you have used in the project. It will also show on the right-hand side the estimated cable length. Keep in mind that you will need some extra cable length for all the height differences.
If you want to know the length of a single ethernet cable, then switch back to the floor plan view and hover with your mouse over an ethernet cable. It will then show the length from the device to the switch.
On the Floor Plan view, you will also find the option to export the design to PDF. This will give you an overview of the equipment and all the floor plan coverage maps. It will also add an installation guide, but that is quite useless. It will for example show how to connect a UDM Pro, even if though we haven’t used on in our project.
Wrapping Up
The UniFi Design Center is a great tool when you want to plan your network wiring and access point placement for your house or office. It’s a little bit of work to draw in all the walls, but it provides you with valuable information when it comes to placing your access points.
You can use the floor plan that you have created in Design Center later in UniFi Inner Space to create a network map with the actual UniFi devices that you have used.
