# devices-unifi-captive-portal-service-guest-6a0707c5

Yes, MyPlace is compliant with most local data regulations, including CCPA and GDPR. You should check if your local data legislation has additional requirements.
Yes, MyPlace works seamlessly with the new UniFi API. This allows controllers with cloud accounts connect and authenticate guests securely.
You’ll need an external portal service - MyPlace provides this. UniFi redirects guests to that portal, they register there, and MyPlace takes care of everything behind the scenes: config, HTTPS, walled-garden allowlists, and the authorization call back to UniFi.
MyPlace UniFi captive portal experience
With the MyPlace UniFi Captive Portal service you can direct any WiFi user that is on the guest network to an external portal server. This service is hosted by MyPlace and all of the data collected is stored in the client dashboard. The user can sign up using Facebook or using their email address. The portal is minimal, light weight and fast while still providing a good user experience.
