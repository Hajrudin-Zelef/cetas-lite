# 26. Source index (all URLs cited, verbatim)

- GitHub stars observed: Prisma `prisma/orm` 47,610; Echo 32.7k `[official site]`; tRPC 37,000+ (cited in API-style coverage).
- State of JS 2025 (reported 2026): Express remains the usage leader; NestJS "progressing at a nice clip" into new enterprise projects `[secondary]`.
- Job-listing proxies: REST in 70%+ of listings; tRPC in ~15% of TypeScript listings and climbing; GraphQL retreating from its ~40% peak to ~25% enterprise `[secondary]`.
- Packagist: Symfony components at ~25% of all PHP installs per the SymfonyCon keynote math `[vendor-reported]`.
- Framework vendors are now shipping **AI-agent skills as a product surface**: Prisma 7.9.0+ (`prisma init` installs skills; MCP safety checkpoint), Hono (official `honojs/skills` + agent CLI + agent-dx measurement), Litestar (`litestar-skills` for six agent harnesses) `[secondary]`. Expect this to become a standard evaluation criterion alongside docs quality.
- **Hiring-pool reality check** (synthesis, not surveyed): largest pools — Spring Boot/Java, .NET, Laravel/PHP, Rails/Ruby, Express/Node; mid — Django/Python, Go, NestJS/TS; smallest — Rust (Axum/Actix), Elixir/Phoenix, Quarkus/Micronaut specialists. Framework performance rarely outweighs team availability in TCO.
- **Longevity bets** (judgment call, labeled as analysis): Spring Boot, .NET, Rails, Django, Laravel, Express are "boring technology" in the best sense — 10-year maintenance horizons are plannable. Quarkus/Micronaut/Hono/Fiber/Litestar are the high-energy challengers — stronger 2026 momentum, smaller hiring pools, faster breaking-change cadence. Both categories are legitimate; the risk profile differs, not the quality.
