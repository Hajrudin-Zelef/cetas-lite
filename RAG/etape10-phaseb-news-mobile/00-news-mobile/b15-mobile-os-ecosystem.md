# B15. Mobile OS & ecosystem

## B15. Mobile OS & ecosystem

- Stable rollout to Pixels in June 2026; wider OEM adoption through H2 2026 `[secondary]`.
- Samsung One UI 8.5 (Android 16) on S26/Z Fold 8; Android 17-based One UI expected with 2027 flagships `[secondary]`.
- Google's 7-year update pledge (Pixel 8+) and Samsung's 7-year pledge (S24+) set the industry bar `[official]`.

### B15.2 iOS 27 (Sept 14, 2026)

- See B8.3. Siri AI beta with daily caps and paid expanded access; Memory Integrity Enforcement; Visual Intelligence; Live Translation `[secondary]`.
- Supported: iPhone 11 and later, iPhone SE (2nd gen+) `[secondary]`.

### B15.3 watchOS 27 (Sept 14, 2026)

- Siri AI (English), dynamic app grid, Smart Stack tap gesture, Workout Buddy without nearby iPhone `[secondary]`.
- Supported: Watch Series 9+, SE 3, Ultra 2+ `[secondary]`.

- Post-quantum cryptography arrived in mobile secure boot (Titan M3) ahead of practical quantum threats `[official]`.

## B16. Connectivity — 5G, satellite, 6G

### B16.1 Satellite messaging

- **Pixel 11**: Satellite SOS `[official]`.
- **Infinix NOTE 60 Ultra**: two-way satellite calling (MWC 2026) `[secondary]`.
- Carrier D2D (direct-to-device) texting expanded through 2026; Apple's Emergency SOS via satellite remained the template `[secondary]`.

### B16.2 5G / 5G-Advanced

- 5G-Advanced (3GPP Rel-18) deployments widened; RedCap IoT variants grew `[secondary]`.
- Modem notes: Pixel 11 switched to MediaTek modems; Snapdragon X-series modems in Elite Gen 5/6 phones; Apple C1X modem in iPhone Air (2025) lineage `[secondary]`.

### B16.3 6G

- 6G remained in research/standardization phase (3GPP Rel-19/20 studies); no commercial launches; 2030 target reiterated `[secondary]`.
- Qualcomm's FlexCache framing cited industry-wide memory shortages — a 2026 supply theme `[vendor-reported]`.

### B16.4 Wi-Fi / Bluetooth / UWB

- Wi-Fi 7 standard on 2026 flagships; Wi-Fi 8 (802.11bn) in development `[secondary]`.
- Bluetooth 6.0 on Pixel 11, Galaxy S26+, watches; UWB on Ultra/foldable flagships (Pixel Tag ecosystem, Samsung SmartTag) `[secondary]`.
- Qi2/Qi2.2 magnetic wireless charging became the Android flagship default (Samsung 20W, Pixel 25W, Xiaomi 50W HyperCharge) `[secondary]`.
