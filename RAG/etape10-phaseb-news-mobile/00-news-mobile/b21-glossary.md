# B21. Glossary

## B21. Glossary

- **LOFIC**: Lateral Overflow Integration Capacitor — sensor tech extending dynamic range (Xiaomi 17 Ultra 1-inch sensor).
- **FlexCache**: Qualcomm's pooled-L2 CPU cache design (Snapdragon 8 Elite Gen 6).
- **Sensing hub**: always-on low-power AI subsystem (Qualcomm) for ambient sensing models.
- **MoE**: Mixture of Experts — model architecture activating subsets of parameters per token.
- **Titan M3**: Google's security chip; post-quantum crypto for secure boot (Pixel 11).
- **Privacy Display**: Samsung's viewing-angle-restricting display tech (S26 Ultra).
- **Qi2.2 / Pixelsnap**: magnetic wireless-charging standard / Google's implementation.
- **Wear Elite SDW6100**: Qualcomm's 3nm smartwatch platform (Galaxy Watch 9).
- **W5 Gen 2**: Qualcomm smartwatch SoC (Pixel Watch 5).
- **S11**: Apple watch SoC (Watch Series 12 / Ultra 4).
- **One UI 8.5**: Samsung's Android 16 skin (S26 generation).
- **D2D**: direct-to-device satellite connectivity.
- **Neural Band**: Meta's EMG wristband for gesture control of smart glasses.
- **APV**: Advanced Professional Video codec (Snapdragon 8 Elite Extreme Gen 6).
- **RedCap**: reduced-capability 5G for IoT/wearables.
