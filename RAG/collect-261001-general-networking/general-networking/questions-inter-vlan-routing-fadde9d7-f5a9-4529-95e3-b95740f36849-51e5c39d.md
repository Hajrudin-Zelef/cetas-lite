Yes,
Move everything back to a single 802.1q routed interface. If you want these two networks to have any communication the easiest approach is to use a router on a stick approach. Then create firewall rules to build the separation you require.
Can you set this up as you have, yes, but because of the way Unifi builds the autogenerated rules it is far easier to keep everything on a single interface.
What you are trying to accomplish is far easier on the edge router since it will not include the self-generated unifi'd rule set.

Any exception need to occur above any rules that block intervlan routing and rules allowing need to allow communication in both directions. A separate vlan is a separate network. The 802.1q protocol allows a primary untagged routed gateway IP plus an theoretically unlimited number of sub-interface gateways co-located on the same physical routed interface.
If you SSH into the router you would see:
eth1 as the base IP network
eth1.x as a sub-interface for vlan x
