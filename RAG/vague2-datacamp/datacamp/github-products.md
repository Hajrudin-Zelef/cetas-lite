## Full summary

This DataCamp guide by Samuel Shaibu provides a complete overview of GitHub's products, from free offerings to enterprise solutions, and highlights tools like GitHub Desktop and GitHub Actions. It also helps readers prepare for the GitHub Foundations certification.

GitHub is more than a code hosting platform — it is a central component of the software development lifecycle, supporting version control essential for collaboration. The main products are GitHub Free (individuals/small teams, unlimited public/private repos, basic collaboration), GitHub Pro (advanced repo insights, extra storage), GitHub Team (team collaboration: multiple PR reviewers, project management tools), and GitHub Enterprise (large organizations: advanced security/compliance, GitHub Enterprise Cloud or Server).

The guide covers account types via a decision tree: Personal accounts (freelancers, students) with GitHub Free and GitHub Pro; Organization accounts (role-based access controls, multiple PR reviewers, centralized billing) with GitHub Free for Organizations and GitHub Team; and Enterprise accounts (SSO, audit logs, flexible deployment) with GitHub Enterprise. It notes managed user accounts: enterprise managed users must sign in to access organization repos, can create private repos, but public publishing/contributions outside the enterprise network are restricted.

A comparison table details account type, plan, price, repos, collaboration, GitHub Actions minutes, security/compliance, deployment options, and ideal use. It notes GitHub Free and Pro include 2,000 Actions minutes; GitHub Free for Organizations and Team include 3,000; Enterprise Cloud includes 50,000 (customizable). Free/Pro/Team/Free-for-Orgs are cloud-only; Enterprise supports cloud or on-premise.

Complementary tools: GitHub Desktop (GUI for managing repos without CLI — clone, branch, commit, push) and GitHub Mobile (review code, merge PRs on the go, manage notifications).

The guide explains billing: subscription-based (Free, Pro, Team, Enterprise with per-user licensing) and usage-based (GitHub Actions, Packages, Codespaces beyond free quotas). Organizations can set spending caps and use usage reports/billing dashboards to control costs. Notifications can be managed via web, email, or mobile, with customization, muting, filters, and triage (marking "Done" or saving for later). The article closes with an FAQ.

## Key points

- GitHub is a central software development platform, not just code hosting.
- Plans: GitHub Free, Pro (personal); Free for Organizations, Team (organization); Enterprise (enterprise).
- Personal accounts suit individuals; Organization accounts add role-based access, multiple reviewers, centralized billing; Enterprise adds SSO, audit logs, flexible deployment.
- GitHub Actions minutes: Free/Pro 2,000; Free-for-Orgs/Team 3,000; Enterprise Cloud 50,000.
- Deployment: Free/Pro/Team are cloud-only; Enterprise offers Cloud or on-premise (Server).
- GitHub Desktop is a GUI for local repo management without command line.
- GitHub Mobile enables on-the-go code review, PR merging, and notification management.
- Billing is subscription-based (plans) and usage-based (Actions, Packages, Codespaces).
- Organizations can set spending caps and track usage via reports/dashboards.
- Managed enterprise users cannot access personal repos; access is limited to the enterprise organization.
- The most fundamental GitHub certification is GitHub Foundations.
