In this **Cisco Packet Tracer configuration** example, we configured **Router on Stick topology**. In other words, we saw **Inter VLAN configuration**. On Packet Tracer, we used one router, one switch and six PCs as hardware. We configured three VLANs and we assigned the interfaces to the VLANs. We also configured router interface 0/0 and create additional router virtual interfaces on this router.


Lastly, we saw that, our PCs in different VLANs can ping each other and Inter VLAN configuration is working properly in our Router on Stick topology. In this lesson we have learned **Router on Stick Config** on Cisco devices.
