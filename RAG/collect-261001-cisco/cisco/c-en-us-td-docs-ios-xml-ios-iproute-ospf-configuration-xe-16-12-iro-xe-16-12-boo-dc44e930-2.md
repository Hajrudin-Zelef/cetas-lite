OSPF Link-State Database Overload Protection
Cisco IOS XE Release 2.1
The OSPF Link-State Database Overload Protection feature allows you to limit the number of nonself-generated link-state advertisements
(LSAs) for a given OSPF process. Excessive LSAs generated by other routers in the OSPF domain can substantially drain the
CPU and memory resources of the router.
