# lesson-huawei-port-security-configuration-on-huawei-ensp-b8a51169

For our last case, we will delete the link of PC4 again and we will configure the switch with the protection action “Protect“.
After this configuration, we will connect PC4 again and send a ping from PC4 to PC1 again. After this ping, there will be no error on the switch screen but the packets to PC4 will be dropped and it will be no PC4 in the MAC Table of the switch.
This is basically Huawei Port Security Configuration on Huawei switches.
