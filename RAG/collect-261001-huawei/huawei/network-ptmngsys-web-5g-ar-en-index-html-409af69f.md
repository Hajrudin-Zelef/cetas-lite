# network-ptmngsys-web-5g-ar-en-index-html-409af69f

NetEngine AR Configuration Examples
      
 
      
       5G offers large-bandwidth, high-reliability, and fast-to-deploy uplinks for enterprise WANs. 5G links provided by the NetEngine AR6000 can serve as the primary links for enterprise interconnection or as backup links for wired links such as Ethernet. In addition, L3VPN and L2VPN tunnels can be set up over 5G links to deliver fast, secure, and efficient data transmission required by enterprises. Browse the configuration examples to learn about the 5G networking, data planning, and data configurations in various scenarios.
