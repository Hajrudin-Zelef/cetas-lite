# hedex-api-pages-edoc1100277644-aem10221-05-resources-vrp-dc-vrp-l2-l2-cfg-5012-h-40b41a7f

After configuring VPLS accessing L2VPN, you can view the binding between the VE interfaces and VE group, and information about VPLS VSIs.
Procedure
- Run the display virtual-ethernet ve-group [ ve-group-id | slot slot-id ] command to check the binding between the VE interfaces and VE group.
- Run the display vsi [ name vsi-name ] [ verbose ] command to check VPLS VSI information.
