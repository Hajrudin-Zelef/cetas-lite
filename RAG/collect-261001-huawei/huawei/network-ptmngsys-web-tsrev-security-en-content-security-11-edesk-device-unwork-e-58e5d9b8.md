# network-ptmngsys-web-tsrev-security-en-content-security-11-edesk-device-unwork-e-58e5d9b8

Check whether the external input power supply is normal based on the power supply specifications of the USG6000 series in the following tables.
| Table 1 Requirements for AC power supply |  | 
|---|---|
| AC Model |  | 
|---|---|
| Rated input voltage (AC) | 100 V to 240 V (50 Hz or 60 Hz) | 
| Maximum input voltage (AC) | 90 V to 264 V (47 Hz to 63 Hz) | 
| Table 2 Requirements for DC power supply |  | 
|---|---|
| DC Model |  | 
|---|---|
| Rated input voltage (DC) | -48 V to -60 V | 
| Maximum input voltage (DC) | -40 V to -72 V | 
Figure 1 shows the PWR indicator. Figure 2 shows the indicator on the power module. Indicators may vary with models.
When the external input power supply provides power normally, the PWR indicator or the indicator on the power module is not steady on green, all indicators are off, and the fan does not work, the device or power module is faulty. Contact the distributor or Huawei Technical Support engineers for hardware repair or part replacement.
