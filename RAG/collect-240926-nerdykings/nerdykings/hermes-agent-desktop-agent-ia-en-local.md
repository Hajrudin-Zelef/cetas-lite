# Hermes Agent Desktop: the first 24/7 AI agent that evolves on its own?

Hermes Agent Desktop is one of the most ambitious open source projects right now: an AI agent capable of persistent memory, using tools, and automating tasks, potentially evolving over time — directly on your PC. I installed it, configured it, and tested it.

## What the project promises

Unlike Hermes WebUI, designed to run on a VPS, this Desktop version installs locally. The ambition remains the same: persistent memory, tools, task automation, and the idea that it gradually becomes more efficient with use. The project is open source, hosted on GitHub (fathah/hermes-desktop), with a dedicated portal at Nous Research for the documentation.

## Installation, configuration, test

The installation, setup, and a first real-world test are covered in the video — as with the WebUI version, the configuration part remains the highest hurdle for a complete beginner. It's a tool that's better suited to those who are already comfortable with VPSs, API keys, and technical environments.

## My verdict

A truly ambitious open source project in the race for autonomous agents in 2026 — but for now, best reserved for those ready to get their hands dirty with configuration. If you're looking for something more streamlined to get started, the WebUI version hosted on a VPS is probably a better entry point.
