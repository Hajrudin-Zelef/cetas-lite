Markdown versions of documentation pages are available by appending `.md` to page URLs; this page is available as [Markdown](https://unsloth.ai/docs/get-started/install/updating.md). # Updating Unsloth Update Unsloth Desktop, Unsloth Studio, or Unsloth Core. ### Update Unsloth Desktop Unsloth Desktop checks for updates automatically after startup. To check manually, open **Settings** → **General** and select **Check for updates**. * **macOS and Windows:** Select **Update now**. Unsloth installs the update and relaunches the app. * **Linux AppImage:** In-app updates are supported for the AppImage build. * **Linux `.deb`:** Download the latest package from the [Linux download page](https://unsloth.ai/download/linux) and install it over the existing version. Debian package installs update manually. Unsloth Desktop updates independently from manual Unsloth Studio and Unsloth Core installations. ### Update Unsloth Studio You can use the same install commands to update #### **MacOS, Linux, WSL:** ```bash curl -fsSL https://unsloth.ai/install.sh | sh ``` #### **Windows PowerShell:** ```bash irm https://unsloth.ai/install.ps1 | iex ``` ### Updating Unsloth Core: ```bash pip install --upgrade unsloth unsloth_zoo ``` #### Updating Unsloth Core without dependency updates:

```
pip install --upgrade --force-reinstall --no-cache-dir --no-deps unsloth
```
