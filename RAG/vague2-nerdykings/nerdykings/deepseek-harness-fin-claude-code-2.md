# DeepSeek Harness : La Fin De Claude Code ?

| Item | Value |
|---|---|
| Project | DeepSeek Harness |
| License | MIT (open source) |
| Core framework | Cortex |
| Modes | Standard, PTC, Minimal, Creator |
| Plugin system | Cordis plugins |
| Model coupling | Model-agnostic (replaceable) |
