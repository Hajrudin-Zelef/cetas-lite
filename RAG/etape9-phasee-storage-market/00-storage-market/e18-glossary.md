# E18 — Glossary

## E18 — Glossary

- **ASP:** average selling price. **WSPM:** wafer starts per month. **LTA:** long-term agreement.
- **DWPD:** drive writes per day (endurance rating). **TBW:** terabytes written (lifetime endurance).
- **PLP:** power-loss protection (capacitors). **HMB:** host memory buffer (DRAM-less SSD technique).
- **P/E cycles:** program/erase cycles per NAND cell. **UBER:** uncorrectable bit error rate.
- **WAF:** write amplification factor. **ZNS:** zoned namespaces. **FDP:** flexible data placement.
- **HBM:** high-bandwidth memory (stacked DRAM). **GDDR:** graphics DDR (discrete VRAM).
- **KV cache:** key-value attention cache in transformer inference. **GQA:** grouped-query attention.
- **CMM-D:** CXL memory module (DRAM). **CHMU:** CXL hot-page monitoring unit.
- **CSD:** computational storage device. **FTL:** flash translation layer.
- **SLED/CADDY:** OEM drive carrier/tray. **RMA:** return merchandise authorization.
