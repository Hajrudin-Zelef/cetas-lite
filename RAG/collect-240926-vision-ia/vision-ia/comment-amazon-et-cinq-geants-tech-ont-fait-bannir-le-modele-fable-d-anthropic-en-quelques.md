# 🧠 **RESEARCH**

**Google Cloud turns scattered docs into Markdown files for agents**

Google Cloud launches Open Knowledge Format (OKF), a minimalist standard that converts an organization's dispersed knowledge into Markdown files with a YAML header, directly usable by AI agents. The format formalizes the "LLM Wiki" pattern recently popularized by Andrej Karpathy. The goal: make knowledge portable, machine-readable, and reusable from one tool to another.

**Code agents find the right file but miss the decisive lines**

A new study introduces SWE-Explore, the first benchmark to evaluate code search and repair separately. Verdict: popular agents like Claude Code and Codex reliably locate the right file, but miss most of the critical lines inside it. Without sufficient context, even the best fix fails, which identifies code search as a major bottleneck for repair agents.

**Mirage: Microsoft gives generated video a spatial memory that forgets nothing**

Mirage, a video world model from Microsoft Research and several universities, stores scene information directly in latent space rather than in pixelated point clouds. Result: significantly reduced compute time and GPU memory, while preserving spatial coherence during long camera movements. Current limitation: tracking moving objects remains imperfect from one segment to another.

**Lookahead Sparse Attention: Tencent compresses long-context memory by 87%**

While Anthropic was wondering "how much can we fit in?", researchers at Tencent asked the opposite question. Their inference architecture, Lookahead Sparse Attention, reduces the memory footprint of a frontier long-context model to only **13.5% of the original**, while maintaining or even slightly improving accuracy. At the scale of 500,000-token contexts, it eliminates more than **90% of memory overhead**, paving the way for far more efficient deployments.

**KPMG inserted entirely fabricated AI case studies into a commercial report**

The irony is total for a document touting the reliability of AI.
