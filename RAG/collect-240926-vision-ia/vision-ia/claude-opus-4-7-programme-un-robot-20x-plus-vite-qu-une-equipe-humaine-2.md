**Recall, the local project memory for Claude Code**: Recall preserves and reuses a project's context between Claude Code sessions, locally and without depending on the API cache. The topic was **picked up by 4 sources** (Hacker News, GitHub, The Rundown AI, Superhuman AI) and has **101 points on Hacker News**. Handy for developers who want true context continuity from one session to the next.

**AWS launches Continuum and Context to make AI agents more reliable**: at its New York summit, AWS unveiled two services. **Continuum** automatically detects, prioritizes, and fixes code vulnerabilities. **Context** builds a knowledge graph from enterprise data to give agents the business context they lack. Two answers to the same problem: agents that code fast but make too many mistakes.

**CleverCrow: tokens to fund open source**: CleverCrow allows supporters of a GitHub repository to offer tokens to maintainers to develop or fix features. The idea addresses the problem of AI-generated, poorly guided pull requests, while leaving maintainers in control of their project. A large-scale test of open source funding (35 points on Hacker News).
