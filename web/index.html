Remote

Serveurs distants (SFTP) utilisables comme projets par l'agent. La clé d'hôte est validée à la première connexion (TOFU) ; les secrets sont chiffrés avant stockage.

Compétences

Instructions réutilisables injectées dans le prompt système de l'agent. Seules les compétences activées sont prises en compte.

Recherche Web

Clés API pour la chaîne de recherche web (Brave → Tavily → Jina → Exa → DuckDuckGo). Sans clé, seul DuckDuckGo est utilisé. S'applique à CETAS et aux Agents.

Ouvrez la Configuration (engrenage en bas de la barre latérale), onglet « API et Modèles », puis renseignez la clé du fournisseur souhaité. Elle est chiffrée avant d'être stockée sur votre serveur.

Le travail agentique (lecture, écriture, exécution avec approbation) se fait désormais dans le module Agents : des conversations indépendantes qui travaillent en parallèle, chacune dans son propre espace (worktree Git isolé). Ouvrez-le depuis les modules en haut de la barre latérale. Le chat général reste une conversation simple, sans outils.

Les agents sont des conversations indépendantes qui travaillent en parallèle, chacune dans son propre espace (worktree Git isolé). Ouvrez le panneau Agents depuis les modules en haut de la barre latérale.

Le terminal ouvre un vrai shell confiné à votre espace de travail, directement dans l'interface. Ouvrez-le depuis les modules en haut de la barre latérale.
